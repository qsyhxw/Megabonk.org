Choose the mod before choosing the loader

Online co-op, same-PC co-op and HUD plugins are different projects. Check the author, game version and loader for the one you need. A BepInEx package and a MelonLoader plugin are not interchangeable installation instructions.

Before changing the game folder

  1. Record the installed game version and make a backup of saves and the current modded folder.
  2. Open the original author’s page. Check whether the package includes a loader or assumes one is already present.
  3. Install one selected project according to its own release instructions. Do not mix loader files from unrelated guides.
  4. Launch and verify the expected menu or HUD before adding anything else. Keep a list of the files you added.

See the co-op guide for online joining and local-controller decisions. For HUD installation, use Nexus Mods · BetterSoulstone ↗. Its author places BetterSoulstone.dll under the game’s Mods folder after MelonLoader setup.

A rollback that preserves other mods

If the expected menu never appears, confirm version, loader and directory first. Revert to the recorded pre-install state before trying a different loader. When several plugins share one loader, deleting its entire folder can remove all of them. Prefer your backup over guessing which shared files belong to which package.

The old Leyren project explicitly targets an Early Access version. Its public source availability does not establish compatibility with the current game.

Why a trainer is a separate check

A trainer modifies a running game through its own application; it is not a replacement for the loader named by a plugin. We have not established a comparative current-version trainer test, nor downloaded or scanned the executables. Do not interpret a provider’s “active” badge as our compatibility or safety verification. This page therefore offers loader decisions, not a tested trainer ranking.
