Find Continue before starting another run

Stay with the same host, browser profile, class and mode. Check the saved-run entry before selecting a new run. In the original’s camp reference, Continue is listed by the waypoint under the saved act; a new-run choice can replace it. Export backups before importing or changing hosts.

Megabonk.org editors · Checked 3 November 2026 · Original references and dated interface captures; no complete-run or save-migration test.

A player asked this after importing a save. It is a menu/host diagnosis, not proof that every missing Continue means the save is corrupt. [3][1][2]

Export, back up the destination, then inspect

  1. Save and exit on the source. Open SAVES and export a file or code; keep it privately.
  2. If the destination already has progress, export that separately too.
  3. Import only the intended source into the intended destination. Read its preview and replacement notice.
  4. Check hero, equipment and the run entry before relying on the new location. Keep both backups.

The current original permits Softcore export/import, not Hardcore migration. This is not a verified cross-version transfer procedure for the older hosted player. We do not upload or inspect your saves. [1]

Continue is an act checkpoint

The current original reference says Continue restarts the saved act at its start state, rather than restoring every second of movement. Other waypoint starts can end that saved run and ask for confirmation. Do not interpret an act restart alone as lost account progress. Older editions can retain different details, so follow their own warnings. [1]

A second tab and a different version are different problems

The original can make a second tab wait while the first owns the save. Close the other game tab before treating the waiting screen as a failed import. If you changed providers, return to the old host rather than clearing storage. If loading fails repeatedly, preserve the backup and report the build and exact message; we cannot guarantee recovery. [1]
