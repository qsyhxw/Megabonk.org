🏆 Megabonk Leaderboards & Submission Guide

Page purpose: This page explains the official Steam status and where community runs are actually submitted. Megabonk has developer-supported leaderboards inside the Steam game, but there is no separate official public leaderboard website that this site can reliably import. The public run data shown on Megabonk.org comes from the independent, video-reviewed Leaderboard.gg Megabonk community board.

Source distinction

  • Steam in-game leaderboard: developer-supported game feature; view it inside Megabonk.
  • Leaderboard.gg: public community board with full-run video review; not affiliated with vedinad.
  • Megabonk.org: read-only community mirror and analysis layer; it does not approve submissions.

How to Submit a Community Run

  1. Open the current Leaderboard.gg Megabonk board.
  2. Choose Submit and provide the requested run and video details.
  3. Follow the patch and form requirements displayed by the board.

For video evidence, prohibited tools and acceptance details, read the dedicated Verification Rules.

How Megabonk.org Uses the Data

  • Hourly source check: GitHub Actions checks the public community dataset once per hour.
  • Stable snapshots: a new commit is created only when the source dataset changes.
  • Real timestamps: source submission and update times are stored alongside first-seen and last-seen observations.
  • Validation: incomplete datasets, missing required fields and duplicate ranks are rejected.
  • No invented rankings: a fetch failure never creates simulated scores or players.

Important: “Verified” on this site means the record is present in the Leaderboard.gg reviewed dataset. See Verification Rules for evidence and review details.

Common Questions

Is Leaderboard.gg the official Megabonk website?

No. It explicitly identifies itself as an independent community leaderboard and is not affiliated with vedinad.

Where can I see the developer-supported leaderboard?

Open Megabonk through Steam and use the leaderboard interface provided inside the game. The Steam store confirms Steam Leaderboards as a game feature, but it is not a public build-data source for this website.

Why can the two leaderboards show different results?

They use different submission and verification systems. Leaderboard.gg requires video evidence and can organize runs by patch, while the in-game system follows the game’s own upload and reset behavior.

Can Megabonk.org submit or remove my run?

No. Submit, appeal or contact the operators directly through Leaderboard.gg. This site only mirrors the approved public dataset.
