Check your save before changing devices

Keep the device with your newest progress open and read its account and Save status first. “Waiting,” “offline” and a successful cloud save are different. This checklist cannot recover a deleted save or prove every missing-progress report has the same cause.[1]

By Megabonk.org editors · Checked October 26, 2026 · Source-based; no comparative gameplay test

Which save state are you looking at?

State / routeWhat the checked source establishesNext useful check
GuestNot a cloud account; saveNow returns a Guest failureDo not assume changing device will carry it over.
Local / offline HTMLBrowser-local storage, separate from cloud modeKeep the same browser profile and game address.
Waiting / pendingAn upload may be queued; success is not yet confirmedKeep the session and connection; inspect the next status.
Offline / failedCloud success has not been confirmedRestore connectivity and record the exact error.
Cloud successThat operation reports successThen compare the account and collection on the other device.

The implementation has separate modes and explicit return states; “the page still opens” does not establish that the server received the latest collection. We have not tested a live account transfer.[1][2]

A cautious order for two devices

  1. Identify the newer session. Note the Pokémon, upgrades and approximate balances visible there.
  2. Check the full domain and account. An independent hosted edition, offline copy or different browser account is not established as the same save.
  3. Finish the run normally where possible. Reloading is not a way to preserve an unfinished battle.
  4. Use Save and read the result. The checked implementation can queue a save because successful cloud writes have a minimum interval.
  5. Wait for actual success. Only then compare the same account on the other device. If it is still different, preserve the newer session and report both states.

The source’s minimum interval is 65 seconds. A response telling you to wait does not mean the upload completed. It also does not mean every failure is solved by waiting exactly 65 seconds.[1]

What players reported, and what it proves

On October 24, SFtittto33 reported progress not syncing between browsers in issue #327. On October 25, NapiCornio independently reported a newer phone save than the PC save in #336.[3][4]

ReportObserved / reported actionEvidence limit
#327 · cross-browserSame account appeared to show different progressOpen at review; no recovery confirmed in the available thread.
#336 · phone / PCReporter said closing the other session, finishing a run and waiting before Save led to merged progressOne person’s successful report; not a blanket fix or permission to overwrite newer data.

These are two distinct reports, not a measured failure rate. A source-code change and a closed issue are different from a successful transfer on your own devices.

Login trouble is a separate branch

The original login screen distinguishes an account linked to Google from an account without that link. If Google was already linked, use that same Google identity through the original website. Do not assume a new account or different email can recover the old one.[5][6]

Issue #331 describes a player who could no longer use the same name/password and had never linked Google. It remained an unresolved report in the reviewed material. This guide has no access to account records and cannot promise password or collection recovery.[7]

Information to keep before asking for help

  • Game address and displayed version; device, browser and browser profile.
  • Whether you used Guest, local/offline or an online account.
  • Last visible newer collection and the exact Save message.
  • Which device is newer, and what changed before the discrepancy.

Do not send passwords, cookies or account tokens. Do not clear site data as the first check: it can remove the local copy you still need.

Rules below refer to JPTER78’s source snapshot 680c3e12c670, reviewed October 26, 2026. Other hosted editions and native ports can differ. We have not completed a comparative run or verified a universal fix.
