Build around the character you have

Choose a class route after checking its current talents and starting spell. Prioritise an engine that already works, then solve the run’s actual failure: crowd clear, boss damage or survival. A finished capstone build is not a fresh-character opening.[1]

Fresh character or developed build?

  1. Read the selected talent. Does it change the opening spell, add a summon, or create a free cast?
  2. Check whether you can actually afford its prerequisites. A named endpoint is not a complete point-by-point levelling plan.
  3. Choose cards for the present engine. An unavailable endpoint cannot supply its damage during the current run.
  4. After the engine functions, choose the next upgrade for the problem that still ends your runs.

Read the trigger before the damage number

TriggerWorks whenA misleading comparison
On a killYou can finish enemies regularly.Treating a crowded wave as isolated-boss performance.
On a critical hitRelevant attacks actually crit.Assuming a health-focused setup has the same proc rate.
While shielded / when a shield breaksThe stated shield condition holds.Counting both conditions as permanently active.
Periodic free castThe granting talent is allocated.Giving a new hero a developed character’s free casts.

These distinctions come from the original talent text; the priority order is editorial synthesis. No simulated DPS or clear-rate ranking is claimed. [1]

Compare attempts without losing the context

Keep the same class, zone, difficulty and permanent investment when judging a change. Then record the engine, one changed choice and the point where the run failed.
