What the current PokeBonk update changes

Original pokebonk.com is v0.8.68 / mvs6j5ov when checked October 28. Team Survival now uses a shared boss every four minutes. Recent changes also include Save and quit and automatic League joins for weakened eligible legendaries. The embedded Play edition remains separate v0.8.27.[1][2]

Save a run without confusing it with a build draft

  1. In an eligible original-game run, open pause and choose Save and quit.
  2. A boss fight or event blocks saving. Wait until the run allows it.
  3. Wait for the game to confirm success before leaving; a failed request is not a saved run.
  4. On return, choose Continue to resume, or Finish to end the stored run and keep earned progress.

These are the original project’s .63 release instructions, not our recovery test. Our website’s JSON backup only contains planning drafts; it cannot back up or restore the original game.
