포케봉크 처음 시작하는 방법

포케봉크는 브라우저에서 실행하는 비공식 포켓몬 팬 게임입니다. 원작의 한국어 페이지에서 처음이라면 게스트, 기존 계정이 있다면 입장을 선택하세요. 다운로드 파일이나 Megabonk 모드는 필요하지 않습니다.

Checked October 28, 2026 · Beta v0.8.62 entry / v0.8.55 mechanics

접속과 앱 배포 정보를 2026년 11월 6일 원작 v0.9.14로 다시 확인했습니다. 다른 표는 기존 확인 날짜를 따릅니다.

최신 빌드와 저장 문제 확인

2026년 11월 11일 원작 v0.9.23을 확인했습니다. Builds → Rental 또는 빌드 계획의 Rent에서 다른 트레이너의 빌드를 복사할 수 있습니다. 제작자, 순위와 부족한 조건을 확인한 뒤 사용할 계획을 선택하세요. 여러 이름의 계획과 계획별 아이템 Archive를 구분해야 합니다.

v0.9.23 공지는 저장한 전투의 이틀 만료와 복귀 시 자동 종료를 수정하고, 복구한 포획을 보존한다고 설명합니다. 기존 브라우저와 계정을 유지하고 Continue 응답을 확인하세요. 설치·복구·실제 기기 성능은 시험하지 않았습니다.

대원정은 11월 19일 17:30 UTC 종료 예정입니다. 철수와 장비 보관 안내 (영어)를 확인하세요. 조토 일일 변이 보상은 v0.9.21부터 모든 포켓몬으로 받을 수 있습니다.

Checked November 11, 2026 against original v0.9.23 / mwaj5w8h. Original release history and definitions and Charcher’s announcements.

원작에서 시작하기

  1. pokebonk.com — 한국어 원작 ↗을 여세요.
  2. 처음이면 게스트 → 손님으로 플레이!를 선택하세요. 기존 계정은 입장, 새 계정은 계정 만들기 탭입니다.
  3. 파트너와 이용 가능한 모드·맵을 확인한 뒤 시작하세요. 먼저 조작을 익히고 긴 생존 기록에 도전하세요.

메뉴는 2026년 10월 28일 v0.8.62에서 확인했습니다. 아래 조작·파트너 설명은 v0.8.55 공개 클라이언트 자료입니다. 실제 기기 플레이나 완주 검증은 하지 않았습니다.

스타터는 지금 필요한 역할로 고르기

원하는 방향후보선택 전 확인
회복을 배우기이상해씨 / Bulbasaur풀 공격과 회복 효과를 함께 확인하세요. 회복에는 발동 제한이 있습니다.
방어 여유꼬부기 / Squirtle방어·보호막과 저체력 조건부 공격 보너스는 다른 효과입니다.
불꽃 중심 공격파이리 / Charmander불꽃 타입 보너스와 물리·특수 피해 보너스의 적용 범위를 구분하세요.

승률 순위가 아니라 패시브 기반 선택 도움입니다. 진화 조건은 본가 포켓몬의 레벨을 그대로 적용하지 말고 이 게임의 진화표 (영어)를 확인하세요.

기본 조작과 화면 확인

행동기본 입력확인할 점
이동 / 시점WASD / 마우스게임 화면을 클릭해 입력 초점을 돌려주세요.
점프 / 슬라이드Space / 왼쪽 Shift설정에서 변경했다면 현재 지정 키가 우선입니다.
상호작용 / 얼티밋E / R근처 상호작용 표시와 준비 상태를 확인하세요.
지도 / 일시정지 메뉴M / P협동에서는 자신의 메뉴가 세션 전체를 멈추지 않습니다.

레벨업 때는 현재 부족한 부분부터 읽으세요. 자주 쓰러지면 회복·방어 효과가 지금 발동하는지, 적을 못 잡으면 선택한 공격의 타입과 피해 분류에 적용되는지 확인하세요.

다운로드·모바일·저장 문제 구분

상황다음 행동피해야 할 오해
APK나 앱을 찾는 중원작 브라우저 경로로 먼저 접속원작 Apps 메뉴의 현재 플랫폼과 다운로드 목적지를 확인하세요.
휴대폰에서 버튼이 작음가로 화면과 게임의 터치 설정 확인모바일 조작 정의가 모든 기기의 성능 보장은 아닙니다.
기기를 바꾸니 진행이 안 보임기존 브라우저를 보존하고 계정 전환 확인새 게스트를 만들면 기존 세션이 자동 복구되는 것은 아닙니다.
로딩 실패표시된 버전·오류·브라우저를 기록저장 데이터를 지우는 것을 첫 해결책으로 쓰지 마세요.

원작 개인정보 안내는 게스트가 60일 동안 사용되지 않으면 삭제된다고 설명합니다. 장기 보관이 필요하면 기존 세션에 접근할 수 있을 때 계정 전환을 확인하세요. 복구 성공을 검증한 것은 아닙니다.

이 사이트의 Play 창은 다른 제공자의 v0.8.27 게임입니다. 원작과 계정·저장이 같다고 가정하지 마세요.

다음 목표에 맞춰 선택하기

빌드: 스타터의 패시브와 현재 공격을 먼저 보세요. 불꽃 보너스와 물리·특수 보너스는 범위가 다릅니다. 융합 재료 두 개를 원하면 기술 슬롯을 먼저 남겨 두세요. 아이템을 많이 모았다는 사실만으로 가장 강한 조합이 되지는 않습니다.

티어: 이 가이드는 통제된 승률 순위를 측정하지 않았습니다. 회복이 필요하면 이상해씨, 방어 여유가 필요하면 꼬부기처럼 현재 문제에 맞는 역할부터 비교하세요.

친구와 플레이: 원작과 같은 계정·버전을 확인하고 협동 방의 생성/코드 참가 조건을 읽으세요. 클랜 가입만으로 같은 전투에 들어가는 것은 아닙니다. 상세 단계는 영어 협동 가이드에 있습니다.

앱과 저장 환경을 먼저 확인하기

원작은 이제 Apps 메뉴에서 앱을 제공합니다. 현재 문구에는 Windows, macOS, Linux, Android가 있으며 v0.8.90은 Android와 Mac 앱을 알립니다. 예전의 브라우저 전용 배포 설명보다 현재 원작 메뉴를 확인하세요. Android 배포만으로 iOS 네이티브 앱을 확인할 수는 없습니다.

독립 오프라인 이식판은 저장 환경이 다를 수 있습니다. 원래 브라우저와 프로필을 유지하고 같은 트레이너인지 확인하세요. 도감 수집, 영구 강화, 완료 기록과 진행 중인 전투를 구분해 문의하세요.

모바일에서 점프만 되고 이동이 안 된다면 v0.9.9 문제와 v0.9.10 수정 여부를 확인하세요. 메뉴 스크롤은 v0.9.12에서 수정되었다고 안내합니다. 팀 일시정지는 v0.8.77부터 모두 동의하면 작동하며, 개인 메뉴를 여는 것과 구분해야 합니다.
