PokeBonk 新手攻略

PokeBonk 是在浏览器里运行的宝可梦同人幸存者游戏。先进入原站，再选择游客或已有账号；不要把 Megabonk 的模组安装教程当成这款游戏的启动方法。本文依据当前菜单与公开客户端整理，没有冒称通关实测。[1]

Checked October 23, 2026 · Beta v0.8.25 · Source-based guide

先找到游戏，再保留已有存档

打开 pokebonk.com — 简体中文原站入口 ↗ (external website, opens in a new tab)。原站提供语言切换；中文与繁体中文是不同选项。页面需要 JavaScript 和 WebGL。若已有游客进度，优先在原来的浏览器和用户配置中进入。[1]

  1. 首次进入时查看 Guest／游客、Enter／登录与 Create account／创建账号几个入口。
  2. 没有旧进度时可选择游客；有账号时使用登录，避免重新开一个游客身份。
  3. 按当前菜单选择初始伙伴，在 League／联盟中查看被动与技能，再进入地区、模式和难度选择。
  4. 进入前先查看 Settings／设置中的 Keys／按键，确认自己是否改过键位。

本次直接检查了入口菜单；后续流程根据公开客户端整理。没有完成游客转换、账号恢复或真实手机性能测试，按钮文案以你当前语言和版本为准。

御三家怎么选

先按你想练的方向选，不必把未经实测的字母榜当结论。下列是 v0.8.25 的被动与技能方向推导，不代表胜率排名。[2][3]

伙伴当前被动重点选择时看什么
妙蛙种子 Bulbasaur+1.5 生命再生、+25% 治疗；草系命中有受频率限制的回复。想练持续恢复时考虑；不是每一个视觉弹体都能无限回血。
杰尼龟 Squirtle+15 护甲、+20 护盾；生命低于40%时另有伤害加成。想先学习走位和防御收益时考虑，不建议为了增伤故意掉血。
小火龙 Charmander+10% 火系伤害；生命低于40%时有伤害加成。想围绕火系技能读升级卡时考虑；不能据此断言通关最快。

完整技能组、被动数值与按目标筛选工具放在英文伙伴对比页；这些技能属于本游戏，不能直接套用宝可梦正作的强度结论。

默认操作速查

当前默认值是 WASD 移动、空格跳跃、左 Shift 滑行、E 交互、R 大招、Q 切换瞄准、鼠标右键锁定、M 地图、P 暂停。升级时 F／X／Z 分别用于当前可用的刷新、跳过与放逐。保存过的改键优先。[2]

角色的装备技能会自动攻击，但仍要控制移动、镜头、瞄准与升级选择。第一次先弄清“移动方向是否跟随镜头”和“附近是否出现交互提示”，再考虑复杂构筑。升级卡先看影响的技能类型或属性，不要只按颜色猜。

手机、APK 与联机要分开看

手机先打开原站浏览器版本。客户端包含触控操作，并不等于所有 iPhone、安卓机型都有流畅运行保证。本次没有验证官方 APK 或 App Store 发行；第三方套壳也不能当成官方安装包。[1][2]

好友、社团和排行榜属于已能从当前资料确认的在线功能；它们不能自动证明可以进入同一张地图实时合作。本次没有验证共享合作局，不承诺上线时间或人数。

游客账号连续60天未使用会按项目政策删除。清理浏览器数据之前，先检查把现有游客保存为账号的选项；本攻略不能替你恢复账号。[4]

游戏问题可向 原项目 Discord 支持 ↗ (external website, opens in a new tab) 提交版本、浏览器和错误信息；本站内容纠错请使用页脚 Contact，不要发送游戏密码。
