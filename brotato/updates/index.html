Brotato Updates — New Dawn, 1.2 and the Beta Branch

New Dawn, update 1.2 and Primal Dread are different content labels. Use Item Sets to inspect enabled content, and check your branch before applying November beta changes.

Developer update history documents the November changes.

Reproduce a guide with Item Sets

The 1.2 announcement introduces switches for expansions and free updates. It gives disabling Paws & Claws while leaving other content active as an example. Open Item Sets from Character Selection and compare the setup with the guide.

If a weapon never appears, inspect enabled content before spending more rerolls. Installed content and enabled content are separate checks.

Check optional participation

Steam Library → Brotato → Properties → Betas shows participation. The 6 November announcement separates balancing from the default branch. It says this balance beta retains progression when changes move to main, and asks players to deactivate and unsubscribe from Workshop mods. Beta instructions

That progression statement applies to this announced beta. Keep your own backup before an experimental setup.

Report a useful discrepancy

Include exact version, branch, map, difficulty, active sets and mods. A tooltip screenshot helps establish which rule you actually have. Use the developer-linked bug forum for reproducible issues.
