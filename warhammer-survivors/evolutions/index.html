How to trigger an evolution

  1. Level the base weapon to its maximum. A partly upgraded weapon never evolves.
  2. Pick up the companion passive. Level 1 is enough; you do not need to max it.
  3. Open the next chest from an elite or boss. With both conditions met, that chest gives the evolution instead of a normal upgrade.

Chest did not evolve? The weapon was not at max level yet when you opened it, or the passive was missing. Max the weapon first, keep the passive, and open the next boss chest. If the companion never shows up in level-up choices, it is still locked: check its unlock.

Older demo pairings you may still see online

Guides written for the first October demo list three pairs that changed: Whirlwind Battery now uses Liquid Green Stuff (not Tape Measure), Nebulous Sea Fog uses Bugman's Tankard (not Glue), and the Age of Sigmar Boltstorm Pistol uses Dice Cube. Dice Cube and Liquid Green Stuff each appear in both universes with a different weapon, so filter by universe before planning a run.

Unlock the companion first

  • Chainsword → Eviscerator Chainsword uses Tape Measure. Unlock Tape Measure by surviving 1 minute with any character.
  • Lasgun → Meltagun uses Gauntlet. Unlock Kozlowski and Lasgun before planning that weapon’s run.
  • Boltgun → Heavy Bolter uses Dice Cube. Check the Dice Cube objective.
  • Whirlwind Battery → Orbital Bombardment uses Liquid Green Stuff.
  • Frag Grenade → Ripper Pistol uses Bandolier. Unlock Bandolier by getting Boltgun to level 4.

Unlocks happen once through Objectives; after that the passive can appear in any run of that universe.
