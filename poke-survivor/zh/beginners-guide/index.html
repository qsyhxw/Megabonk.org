Poke Survivor 中文入门攻略

先打开 JPTER78 的 pokesurvivor.com，选访客或账号入口，再确认伙伴。移动负责躲避，当前选中的招式自动攻击；学会四个招式不代表四招同时释放。离开或换设备前，要检查保存状态。[1]

By Megabonk.org editors · Checked October 26, 2026 · Source-based; no comparative gameplay test

English beginner guide

游戏本身已提供简体与繁体中文

本次核对的原站语言脚本明确列出简体中文、繁體中文。优先使用已经保存的语言设置；没有保存设置时，/en/ 路径优先显示英文，再根据浏览器语言选择。zh-TW/zh-HK/zh-MO对应繁体，其余中文识别通常对应简体。需要中文时，先在游戏设置中检查语言，不必先安装第三方汉化脚本。[2]

旧攻略里“只有英文和西班牙文”的说法不能直接套用本次版本。本文查阅了原作者简繁词典；不声称已经在实体手机上验证全部中文界面。[3][4]

认准项目，再开始第一局

原作者入口：pokesurvivor.com 原站 ↗ (external website, opens in a new tab)。PokeBonk 是另一款游戏；Pokémon Survivor Burst 和第三方原生端口也有各自规则。不要把它们的账号、联赛或进化表混用。[5]

  1. 已有进度时先回到原来的网址、浏览器资料和账号。
  2. 首次进入，访客适合短暂查看；不要把访客当成云端账号。
  3. 按性格问题得到初始伙伴建议，不合适可以选择另一个。源码列出29个初始伙伴。
  4. 开始前先看控制设置和存档状态，不急着复制最强配装。
[6]

只需要先记住这些操作

操作键盘触屏/手柄
移动WASD 或方向键拖动移动 / 摇杆或方向键
选择主动招式1–4；Q/E循环点击招式 / LB、RB
使用宝珠5–8点击宝珠 / X使用、Y切换
暂停Esc暂停按钮 / Start

以上为作者指南记录的默认操作，已保存的自定义设置优先。手机先横屏检查按钮位置；四个招式槽并不默认一起输出，Bond（羁绊）才会改变同一主动组里同时发动的招式。[1]

把卡片原名与用途一起读

卡片/概念先理解什么适用判断
Vigor / 活力最大HP增加20，并补满新增部分与立即按比例回血不是同一种效果
Power / 威力本局伤害增益仍要看你当前正在用什么招式
Sprint / 奔跑本局移动速度帮助移动，不是永久速度培养
Reflexes / 反应招式冷却缩短与学一个新招式不同
Sitrus Berry立即回复最大HP的45%当前血量危险时读清即时效果
New move / Move upgrade新招式 / 已有招式升级新学的未选中招式不一定正在攻击

英文名保留作对照，实际中文以游戏当前词典为准。局内卡片不会自动变成伙伴永久培养；先读效果，再按当前问题选，不把这张表当通用升级顺序。[7][3]

超梦与纸御剑：先分物理、特殊

查询中出现超梦（Mewtwo）、无极汰那（Eternatus）、凯路迪欧（Keldeo）、纸御剑（Kartana）与请假王（Slaking），不等于它们都是新手免费初始伙伴或有相同获取方式。

以源码字段为例，Mewtwo物理/特殊倍率分别为1.31/1.55，Kartana为1.70/1.02。用两者较大值当所有招式的倍率，会误判配装。这些字段不含完整招式、特性、道具和实际走位，不能直接推出综合最强榜。[8]

先看攻击是物理还是特殊，再配Swords Dance或Nasty Plot；完整五角色对照见英文构筑核对表，不是全角色强度排名。[9]

招式进化、物种收藏、永久升级要分开

可进化招式需要本局达到其等级和属性卡条件，再选择金色进化卡。例如Ember与Power、Quick Attack与Sprint的配对来自本次源码定义。菜单里买过永久升级，不等于本局已经拿到那张属性卡。[9][7]

这也不能证明伙伴物种永久进化或已经解锁对应收藏。误学TM或伙伴培养退款目前没有本文核验过的逆转流程；功能请求不能当现成功能。花费前检查伙伴和招式对象。[10]

结束前检查：本地保存不等于云端成功

访客、离线HTML、本地账号与在线云存档不是同一条路径。源码会区分等待、离线、失败和成功；显示等待时不要马上换设备，认为新伙伴已经上传。保留进度较新的设备和会话，先核对网址与同一账号。[11]

第#331号原始问题记录了未绑定Google时用户名/密码无法登录的情况；这里不能承诺恢复账号或找回已丢失收藏。不要把新建账号当恢复步骤。[12]
