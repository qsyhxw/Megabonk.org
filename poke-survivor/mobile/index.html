Poke Survivor on mobile

Start with pokesurvivor.com in your phone’s browser. That route needs no APK. An installed web shortcut, the author’s offline HTML copy and a third-party native port are different choices; check the save boundary before switching.[1]

By Megabonk.org editors · Checked October 26, 2026 · Source-based; no comparative gameplay test

Español: jugar y descargar

Start at the original browser game

pokesurvivor.com — original game ↗ (external website, opens in a new tab)

  1. Keep the same browser profile if it holds your progress.
  2. Start in landscape and check movement before a longer run.
  3. Inspect Settings → Controls; saved layouts may differ from defaults.
  4. Check the account and Save state before moving to another device.

The creator documents touch and controller support. That establishes available controls, not smooth performance on every phone. No physical-phone test or FPS benchmark is claimed.

The V5.1 port release describes different Tower, fusion and Arceus rules. Do not apply its endgame rewards or run duration to the original browser game. We did not install its executables or test save migration.

Separate movement, slots and controller input

Drag to move and tap a move to make it active. Automatic attack does not mean every learned move fires at once. The creator documents stick/D-pad movement, LB/RB slot cycling and Start to pause on a connected controller. First check what your browser and Controls screen actually detect.

If only a touch region fails while menus still respond, note its position and orientation. If the clock also stops, use the general freeze checklist instead. Switching browser profiles before checking saves can hide the local copy you still have.

[1]

Dated touch and installation reports

In issue #337, opened October 25, g4to12 reported the joystick stopping. Two other commenters corroborated on October 26; issue #341 is another mobile movement report. This is a cluster of reports, not a tested universal fix.

[4][5]

On October 26, DrAstroLR reported a Chrome-installed web app failing to launch on HyperOS, and described opening the website and using its install action to launch the existing installation. This is one person’s workaround; it does not establish that deleting data or reinstalling is needed.

[6]

Choose the next check

  • Input: inspect the layout, orientation and exact unresponsive action.
  • Save: preserve the newer device and read the Save result.
  • Performance: record when it slows and the current settings; lower graphics is not a proven joystick fix.
  • Report: include address, build, browser and symptom, not passwords.

Rules below refer to JPTER78’s source snapshot 680c3e12c670, reviewed October 26, 2026. Other hosted editions and native ports can differ. We have not completed a comparative run or verified a universal fix.
