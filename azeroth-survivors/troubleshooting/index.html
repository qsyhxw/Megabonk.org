Find the cause before reloading your game

Match the visible symptom first: no WebGPU, no usable graphics adapter, loading that still advances, or a server refusal. Keep an export before changing browser, host or stored data. The local check below tests capability; it does not test the game server or guarantee a playable run.[1]

If loading stops or the screen stays black

  1. Record the exact message and whether a progress counter changes.
  2. Open the original directly in its own tab; do not import your only save into an unfamiliar host.
  3. If graphics capability is missing, inspect the browser’s acceleration setting and graphics diagnostics, then restart after a relevant change.
  4. If capability is available but the game still fails, keep the host, game version, device, browser and failure stage with your report.
  5. Use the creator’s linked download or community route when the browser route is unsuitable. Do not erase storage as a generic loading fix.

A low frame rate is a different problem

If the game reaches the world, first compare its graphics/display settings and reduce background GPU load. Change one setting at a time. An addon error, an overloaded GPU and a server refusal require different checks; no FPS improvement or universal preset is measured here. Preserve the existing save before testing a different client.[2]

What to include when asking for help

Include the exact host, displayed game version, browser/OS, device, visible error and whether failure happens during download, preparation, menus or a run. Share relevant screenshots without account or save contents. Discord · creator community linked by the original launcher ↗ (external website, opens in a new tab)[1]

When the client says an update is waiting

The v0.139 text distinguishes an up-to-date result, an update check failure, a download in progress and a newer version waiting in the hero picker. Record the exact result and displayed version. A failed update check alone does not establish a GPU failure; preserve a save export before changing client or host. These prompts were checked in client strings, not by completing the update flow.[2]
