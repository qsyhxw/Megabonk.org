PokeBonk 新手攻略

PokeBonk 是在浏览器里运行的宝可梦同人幸存者游戏。先进入原站，再选择游客或已有账号；不要把 Megabonk 的模组安装教程当成这款游戏的启动方法。本文依据当前菜单与公开客户端整理，供首次进入时查阅。

Checked October 25, 2026 · Beta v0.8.48

入口、应用发行、杰尼龟被动及合作暂停于2026年11月6日按原站v0.9.14复核；其余旧版操作资料保留原日期。

先找到游戏，再保留已有存档

打开 pokebonk.com — 简体中文原站入口 ↗。原站提供语言切换；中文与繁体中文是不同选项。页面需要 JavaScript 和 WebGL。若已有游客进度，优先在原来的浏览器和用户配置中进入。

  1. 首次进入时查看 Guest／游客、Enter／登录与 Create account／创建账号几个入口。
  2. 没有旧进度时可选择游客；有账号时使用登录，避免重新开一个游客身份。
  3. 按当前菜单选择初始伙伴，在 League／联盟中查看被动与技能，再进入地区、模式和难度选择。
  4. 进入前先查看 Settings／设置中的 Keys／按键，确认自己是否改过键位。

本次直接检查了入口菜单；后续流程根据公开客户端整理。没有完成游客转换、账号恢复或真实手机性能测试，按钮文案以你当前语言和版本为准。

御三家怎么选

先按你想练的方向选，不必把未经实测的字母榜当结论。下列被动方向已于2026年11月6日按v0.9.14复核；技能与进化资料保留各自日期，不代表胜率排名。

伙伴当前被动重点选择时看什么
妙蛙种子 Bulbasaur+1.5 生命再生、+25% 治疗；草系命中有受频率限制的回复。想练持续恢复时考虑；不是每一个视觉弹体都能无限回血。
杰尼龟 Squirtle+15 护甲；每8秒获得相当于最大生命8%的护盾；有护盾时伤害×1.25。想先学习走位和防御收益时考虑，不建议为了增伤故意掉血。
小火龙 Charmander+10% 火系伤害；生命低于40%时有伤害加成。想围绕火系技能读升级卡时考虑；不能据此断言通关最快。

进化要看本游戏的局内阈值，而不是正作等级；当前伊布还会弹出分支选择。详见 进化规则与等级对照（英文）。完整技能组、被动数值与按目标筛选工具放在英文伙伴对比页；这些技能属于本游戏，不能直接套用宝可梦正作的强度结论。

默认操作速查

当前默认值是 WASD 移动、空格跳跃、左 Shift 滑行、E 交互、R 大招、Q 切换瞄准、鼠标右键锁定、M 地图、P 暂停。升级时 F／X／Z 分别用于当前可用的刷新、跳过与放逐。保存过的改键优先。

角色的装备技能会自动攻击，但仍要控制移动、镜头、瞄准与升级选择。第一次先弄清“移动方向是否跟随镜头”和“附近是否出现交互提示”，再考虑复杂构筑。升级卡先看影响的技能类型或属性，不要只按颜色猜。

手机、APK 与联机要分开看

手机先打开原站浏览器版本。客户端包含触控操作，并不等于所有 iPhone、安卓机型都有流畅运行保证。原站现有 Apps 入口，当前文案列出 Windows、macOS、Linux、Android，v0.8.90明确宣布安卓和Mac应用。请从原站确认下载目的地；安卓发行不能证明存在iOS原生版，独立离线移植也须另查账号和存储规则。

当前客户端已提供2–4人的合作 Beta：在 Co-op／合作入口查看开放状态，由一人创建房间，其他人使用邀请或房间代码加入。关闭测试、维护与临时暂停是不同状态，以你账号实际看到的提示为准。本次核查了公开客户端及更新记录，没有完成真实多人局或跨设备测试。

v0.8.77起可按P请求团队暂停，全员接受后停止，单局预算5分钟，全员投票后继续。只打开个人菜单不等于团队已暂停。升级保护改为45秒初始储备，每级加15秒、上限90秒并逐渐恢复；v0.9.13修复大招或升级后泡泡不消失的问题。遇到版本不一致提示时，队员先刷新原站并核对版本，再开始。10月25日的更新还加入共享地图发现，以及从房间进入实验室后返回房间的入口。

不要继续使用 v0.8.45 的团队封印／连接精英攻略：v0.8.46 已撤回这些机制。完整创建、加入和故障提示说明见 合作模式攻略（英文）。

原项目政策说明：游客账号连续60天未使用会被删除。清理浏览器数据之前，先检查把现有游客保存为账号的选项；本攻略不能替你恢复账号。

游戏问题可向 原项目 Discord 支持 ↗ 提交版本、浏览器和错误信息；本站内容纠错请使用页脚 Contact，不要发送游戏密码。

换浏览器后先检查账号，再判断进度

  1. 保留原来能访问进度的浏览器，核对完整网址。
  2. 确认同一训练家账号，区分已有游客、新游客和命名账号。
  3. 分清缺少联盟成员、实验室升级、结算记录还是局内继续。
  4. 查看当前保存或账号转换的成功提示，再核对结果。

原站v0.8.85宣布账号支持跨设备继续，但这不能证明可把存档导入非官方离线移植。v0.9.14对远征长局卡在“进行中”给出的操作是：回到同一浏览器，先不开始另一局，让它重新保存。

手机只能跳不能移动时，先核对是否为v0.9.9摇杆问题及v0.9.10修正；菜单无法滑动则查看v0.9.12修正。持续故障记录设备、版本及具体界面。
