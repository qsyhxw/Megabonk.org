What the current PokeBonk update changes

The original version record and menu read v0.8.55 / mvob1c8t on October 26, 2026.[3] Its release entry is dated October 25. The practical change is extra Archive capacity from item unlocks and a move-upgrade summary in pause; earlier co-op and graphics changes affect different tasks.[1][2]

Checked October 26, 2026 · Beta v0.8.55 · Source-based guide
