Play a card
Drag it onto an enemy, or click the card and then the target. Keys 1–9 pick a card.
Energy
The red orb refills every turn, so spend it all.
Potions
Press a potion in the belt and drag the arrow onto an enemy. Esc cancels.
Intents
The icon above an enemy is its next move; a sword and a number is an attack for that much.
End turn
The button, or Space / E. Esc opens the menu, F is fullscreen.

A familiar world, played one card at a time

Spires of Azeroth combines a branching roguelike climb with Warcraft-inspired spells and enemies. You choose a class, draft cards as the run develops, equip gear and tackle the bosses of each spire. Your hand and resources constrain what you can do this turn; clicking End Turn lets the enemies act. It is a fan game, not Blizzard's MMO or an expansion for Slay the Spire.

The author lists nine classes and 40 Classic zones. That is the project's advertised scope, not a claim that we cleared every zone. Browser build 20261103e was inspected on 4 November 2026; desktop releases have their own version numbers.)

From Choose class to your first battle

  1. Click Play above and wait for the game's own title menu. The outer frame loading is only the start of resource loading.
  2. Select Choose class. With no saved character, the current version opens character creation. Choose a race and class, enter a name, then Accept.
  3. Select the character and use Enter World. Review the starting continent and difficulty controls before entering; use the basic starting difficulty for a first look.
  4. Choose an offered zone, then a reachable node on the map. Zone choices and encounters can vary between runs.
  5. In combat, inspect the enemy's intent and your hand. Play a card on a valid target, then end the turn when you have finished your actions. Read the next reward before adding it to your deck.

This starting path was checked in the original browser interface on 4 November. It is not a full-clear route or a strongest-class recommendation.

Pick a class for the decisions you enjoy

All nine Classic class names appear in the project: Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock and Druid. Their card themes differ: Warrior uses stances and rage; Rogue builds and spends combo points; Druid changes forms; Mage offers Frost, Fire and Arcane spells. These are identity cues from the author's description, not a power ranking. Read the chosen class's starter deck in the game before committing.

Equipment and talents add another layer to the climb. Do not copy an Azeroth Survivors talent allocation into this game: matching spell names do not make the rules or saves interchangeable. Compare the game identities →.

Choose the right next step

Want an app? Choose Windows, macOS, Linux, Android or the iOS browser route. The author's desktop packages need the internet on first use and do not automatically share your browser progress.

Blank or stalled game? Allow resources to load, then try TheWoWDB · original in its own tab. Note the host, displayed build and exact error. Do not clear site data as a first step: it can remove progress. An external game outage cannot be repaired by refreshing this guide.

Returning to a run? Use the same host and browser profile and look for Continue run in the game. Before switching versions, use its own save export where available and keep both source and destination backups. We have not verified cross-platform imports, co-op completion or every browser.

Common questions

Is Spires of Azeroth free to play?

The author describes it as a free browser game with free desktop and Android versions. Solo play needed no game account when we checked on 4 November 2026.

Full answer →
Is it the same game as Azeroth Survivors?

No. Spires of Azeroth is turn-based card combat on a climbing map; Azeroth Survivors is a separate automatic-spell survival game by another author. Saves and builds do not carry over.

Full answer →
Can I play Spires of Azeroth on my phone?

The game window loads in a mobile browser, and the original menu gives a Safari Add to Home Screen route for iPhone and iPad. We tested browser sizes only, not a physical phone, so a landscape view or a larger screen is safer for reading small cards.

Full answer →
Does Spires of Azeroth have co-op?

The original title menu shows a Co-op button (seen 21 November 2026). No co-op session has been run for this guide, so it does not describe how co-op works.

Full answer →
Will my saved run move between the browser and the app?

Not automatically. The author says desktop saves are separate from the browser, and a framed game and a separate tab can store progress differently. Back up first and keep the same host and browser profile.

Full answer →
What should I pick first as a new player?

Any class can start a first run. The guide gives class identity cues, not a power ranking: choose the card style you enjoy and read the starter deck in the game before you commit.

Full answer →
The game window is blank. What do I do?

Wait for resources to finish loading, then open the original in its own tab. Note the host and build shown, and do not clear site data first because it can remove progress.
