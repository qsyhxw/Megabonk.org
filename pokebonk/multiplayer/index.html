PokeBonk multiplayer: what is confirmed?

Clans, friends and online leaderboards are documented in the current client. A working shared co-op run was not verified in this review. Do not treat an online account, a clan invite or a visible friend as proof that you can enter the same arena together.[1]

Checked October 23, 2026 · Beta v0.8.25 · Source-based guide

Online features are different player tasks

The project’s account notice documents saved progress, rankings, clans and trainer profiles. The current client also includes friends and invitations. These are concrete online services, but their presence does not establish real-time shared combat.[1][2]

If your goal is to play alongside friends

First agree which task you mean. If you want to compare records or take part in clan activity, use the relevant social menu in the original game. If you want everyone in one arena, require a visible shared-session flow before making plans around it.

  1. Check that everyone is on the same original game and current build.
  2. Use the Friends or Clan features for their stated purpose; read whether the action adds a friend, invites a member or joins a run.
  3. For a new co-op announcement, look for host/join instructions, eligibility and the actual session entry point.
  4. If no shared-run action is present, ask the project’s support rather than following instructions for a different game.

A trainer name is enough for many social actions. A friend does not need your password or browser session.

How to verify a new co-op claim

Read the original game’s current What’s new panel and compare the version shown below the logo with the project’s current version record ↗ (external website, opens in a new tab). A version record identifies a build; it does not by itself announce multiplayer support.[3]

Look for a dated project announcement that explicitly names shared runs, then follow its actual entry steps. We did not verify a co-op player cap, cross-play guarantee, PvP mode or release date from the sources inspected. Old roadmap estimates should not be written as launch dates.

For a current answer from the project, use PokeBonk Discord support ↗ (external website, opens in a new tab). Keep the game version with the question so the answer is tied to the same client.

Is this the Megabonk multiplayer mod?

No: this guide covers the separate PokeBonk browser project. Megabonk mod instructions describe a different game and installation path. Installing a Megabonk co-op mod does not add a PokeBonk shared session.

If the video you watched uses Steam, a mod manager or Megabonk character names, check the game identity before following it. The PokeBonk starting point here is pokebonk.com.
