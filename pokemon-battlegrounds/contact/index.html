Contact the Pokémon Battlegrounds guide editors

Reviewed 22 November 2026

Email

Write to contact@megabonk.org. Useful reports for this section:

  • A game address, sign-in option or practice mode that no longer matches the home page;
  • A control key or in-game help line that reads differently in the current client;
  • A wrong link, screenshot or project name in the “which game” table.

Include the page URL, the device and browser you used and what the game showed. Do not send passwords or sign-in codes.

What we cannot help with

We do not run PB Ranked, so we cannot recover an account, restore a team or change a rating. Use Report a problem inside the original client, or the developer contact on its privacy page ↗.
