Contact the Spires of Azeroth guide editors

Reviewed 21 November 2026

Email

Write to contact@megabonk.org. Useful reports for this section:

  • A first-run step, control or menu that no longer matches the original’s current build;
  • A download route, package name or version line that has changed;
  • A wrong class, card or save statement, with the screen where you saw it;
  • A broken link, image or layout on a Spires of Azeroth page.

Include the page URL, the host (original, our game window or an app package), the build or version shown and your browser or operating system. A screenshot helps us confirm the fix quickly.

What we cannot help with

We are not the game’s author or support, so we cannot recover a lost save, read the storage of another website, install a package for you or change how the game works. For those, use the project’s own GitHub repository ↗ and keep the backups described on the saves & versions section.
