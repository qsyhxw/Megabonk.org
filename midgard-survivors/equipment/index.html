How to equip another armor

  1. Complete the run and review the item choices shown at its end.
  2. Select the items you want to keep.
  3. Return to character selection and find Gear at the bottom.
  4. Compare the item with your equipped piece and check the displayed changes.
  5. Use Q during the next run to inspect equipment.

The first four steps follow the answer to “How can I equip other armors?” in the Baphomet discussion ↗ (opens in a new tab). This route has one player report. The Q shortcut is documented separately on the developer’s itch.io page.

Separate the two progression decisions

The developer’s October devlog ↗ (opens in a new tab) describes permanent equipment, permanent cards, refining and slots. The current listing places Kafra upgrades, refining, food and pets between runs.

DecisionWhere to checkWhat to compare
Level-up skill offerDuring the current runThe offered effect and the enemies you face now.
Retained armor or weaponGear after the runThe displayed stats and requirements before replacing a piece.
Permanent upgradeProfile or the relevant town serviceThe next upgrade effect and its cost.
RefiningThe refinerRequired material and displayed risk before confirming.

Use these as separate review points when a completed map sends you back to start another attempt. Keep an item change and a permanent upgrade identifiable so you can tell what changed.

Before refining or changing a build

The developer listing ↗ (opens in a new tab) names Oridecon and Elunium and says refining can fail. Read the current client’s cost and failure explanation before spending. The sources checked here do not establish a universal safe refine threshold or a best armor set.

If Gear is missing in your build, record the version and menu screen for feedback. Use the reported route as a navigation lead, then verify the displayed item and effect before committing resources.
