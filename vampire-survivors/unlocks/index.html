A manageable run plan

  1. Write down one unmet objective, its stage, character and any required item.
  2. Check that its prerequisite character or weapon is selectable.
  3. Use that run to satisfy the specific condition. Add a second objective only when it shares the same setup.
  4. Return to the menu and distinguish the new unlock from purchases or in-run acquisitions still needed.

For the character-specific level-80 task, follow the Cherry Bomb and Chaos Rosalia route.

This is an editorial planning method. It is not a mandatory order for every achievement.

Keep DLC progression separate

When the list becomes crowded, pick one expansion’s objectives at a time. Our DLC comparison identifies the packs, while Castlevania checkpoints explain its gates. This roadmap covers the early main stages and key systems, not every unlock in every version.
