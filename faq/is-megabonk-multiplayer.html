Is Megabonk Multiplayer or Co-op?

No. Megabonk does not have native multiplayer or co-op. Version v1.0.69 is officially Single-player, with no built-in online co-op, local or couch co-op, split-screen, PvP or matchmaking.

Official: Single-playerOnline Co-op: NoLocal Co-op: NoRemote Play Together: No

Quick Answer

Megabonk is a solo game. The official Steam feature list includes Single-player but does not list Online Co-op, Shared/Split Screen, multiplayer or Remote Play Together. Steam Link can stream that same solo session to another device; it cannot create a second character or shared run.

Remote Play Does Not Add Co-op

Steam Link / Remote Play Anywhere

These features stream video, audio and controls from the host PC. You can continue the same solo run on another device or hand control to a friend, but there is still only one player character.

Remote Play Together

This Steam feature shares a game's existing local multiplayer mode with remote friends. Megabonk has no native local co-op and Steam does not list Remote Play Together, so it cannot produce simultaneous vanilla co-op.

Screen sharing, taking turns or racing separate runs can be social, but none of them changes the official Single-player classification.

Official Status vs Multiplayer Mods

Community projects can add networking, but they are not part of the base game. Their versions, dependencies, player limits and compatibility can change independently of Megabonk.

Is Official Multiplayer Planned?

There is currently no official multiplayer roadmap, release date or confirmed co-op update on the Steam store page or in official patch announcements checked through v1.0.69.

That does not prove multiplayer can never happen; it means there is no reliable announcement to schedule around. Buy and play the current game as a single-player title, and treat forum speculation as unconfirmed until the developer updates the official feature list or patch notes.

Multiplayer FAQ

Is Megabonk multiplayer?

No. The official game is Single-player and has no native multiplayer mode.

Does Megabonk have online or couch co-op?

No. Vanilla Megabonk has neither online co-op nor local/couch co-op.

Can two people play Megabonk on one PC?

Not simultaneously in the base game. There is no local co-op or split-screen mode.

Can Remote Play Together make it co-op?

No. Megabonk is not listed with Remote Play Together, and it has no local multiplayer mode for Steam to share.

Can Steam Link stream Megabonk?

Steam Link can stream the same solo session to another supported device, but it does not add another player.

Are multiplayer mods available?

Yes, unofficial community projects exist. Use the dedicated Mod Guide for current packages and risks.

Has the developer announced official co-op?

No official roadmap, release date or confirmed co-op patch was available when checked July 27, 2026.
