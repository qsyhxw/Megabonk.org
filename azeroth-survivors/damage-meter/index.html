Turn on the meter, then compare the right numbers

Open Options and enable Show Damage Meter for the built-in meter. Add AZS Spell Meter only if you need its per-spell views and configurable DPS window. A ten-second DPS number and a whole-run average answer different questions.[1][2]

Megabonk.org editors · Reviewed 29 October 2026 · Original v0.127.0 · Source-based, not a playtest

Start with the built-in meter

  1. Open Options and find Show Damage Meter in the HUD/interface settings.
  2. Enable it, then use the meter’s minimap button or window.
  3. Adjust HUD Scale if it is too small; Damage Meter on Top controls whether it stays over upgrade cards.
  4. Select the view that matches the question: total damage, healing, boss damage or party output.

Client messages include “No damage yet”, “No healing yet” and “Only in a party”. An empty view before its relevant event is not by itself an addon failure. [1]

Choose a measurement window

QuestionUseful view/windowKeep constant
Did this change improve recent wave clear?A recent DPS windowCompare the same minute, difficulty and starting investment.
What dealt the most across the run?Whole-run damage/shareRun duration; a longer attempt has more time to accumulate damage.
What reached the boss?Boss viewThe same boss and similar gear/talents.
Which effect created a proc’s damage?Per-spell row and proc breakdownThe addon version and grouping method.

kex0 documents a default ten-second window, configurable settings and a “Since the start” average. The author also groups proc damage under the spell actually cast; a different row label can reflect attribution rather than missing damage. [2]

When using AZS Spell Meter

Install the author’s addon → first. Commands documented by the author are /azsm to show/hide, /azsm resetpos to restore position and /azsm lock to lock dragging. The title-bar settings control the DPS window and columns. While an addon window is open, its author says the built-in Damage Done meter is hidden; closing all addon views restores it if it was enabled. [2]

Do not promote one number into a tier list

Record class, capstone, zone, difficulty, permanent gear and time before comparing two readings. A kill-triggered build in a dense wave and a shield build against a lone boss are not the same experiment. An impressive screenshot does not establish the best class for a fresh save. Check each build’s trigger →

The author reports v1.32 tested with game 0.123.0. We inspected the original 0.127.0 text, but have not run a compatibility benchmark with that addon; check the latest author release if a view behaves differently. [2]
