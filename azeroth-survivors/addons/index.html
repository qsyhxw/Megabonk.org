Install an addon in the right client

In the browser, use Options → AddOns → Install AddOns and select the author’s ZIP. On desktop, use the AddOns folder opened by the game and match the folder name to its .toc file. Browser installation and desktop extraction are different paths.

ASBuilder online and the in-run addon

Use the ASBuilder guide → for online class/loadout planning, stages, ASB2 codes and browser backups. ASBuilds.app now has Loadout, Talents and Armory views. The separate addon opens with /asb and shows planned priorities in-game.

The web editor and addon have different talent-data boundaries. The author’s addon README still describes a screenshot link because addons cannot read game talent data. The browser installation steps below describe the original client menu, rather than a verified ASBuilder install.

Which UI project did you mean?

Start with the stock interface if you only need the built-in meter. A replacement HUD changes more of the screen; compare its documented controls before adding another package. Several projects use similar Survivor UI names, so match the repository owner as well as the addon name. Author documents checked 3 November 2026; these packages were not installed here.

  1. Export your game progress and note existing addon settings before changing the interface.
  2. Choose one replacement HUD first. Two packages using the same folder or command are not automatically compatible.
  3. Follow that author’s folder and release instructions; use the browser ZIP installation path below only where the package supports it. A Windows launcher cannot be assumed to run inside a browser.

Browser: keep the ZIP intact

  1. Download the chosen addon ZIP from its author.
  2. Open the original game’s Options → AddOns → Install AddOns.
  3. Choose the ZIP and inspect the installed entry; enable the addon in the list.
  4. Start the next run so the game can load it. Install an updated ZIP through the same menu when the author releases one.

The browser installer stores files in IndexedDB for that browser and origin. They do not automatically follow the save file to a second device; clearing site storage can remove them.

Desktop: check the directory level

  1. Open Options → AddOns → Open AddOns Folder in the downloaded game.
  2. Extract the author’s addon into that folder. For AZS Spell Meter the author documents AddOns/AZSSpellMeter/AZSSpellMeter.toc.
  3. If the extracted directory is AZSSpellMeter-main or has another wrapper folder, rename or move the actual addon folder so its name matches the .toc.
  4. Relog as the addon author instructs, then check the addon entry again.

Optional native helpers such as DLL updaters are separate from Lua addon files and cannot be assumed to run in the browser. This guide does not require installing a native helper.
