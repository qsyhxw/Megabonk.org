Find the next zone for the class you selected

The original v0.130.0 picker lists twelve zones. Defeat the preceding zone’s final boss to open the next for that class. Another class’s progress does not automatically open your selected hero’s route.[1]

Scholomance and the displayed encounter clock

Checked 11 November 2026 against original v0.143.2. Scholomance, subtitled The Great Ossuary, is now present in the original client, with Darkmaster Gandling named in its zone description. The twelve-zone table below preserves the 30 October route. Inspect the current picker for Scholomance access before planning a run.

Read the selected mode before using an older boss timer. The current client includes Hyper Mode and a Heroic V unlock prompt. Use the requirement shown in your Difficulty panel, then check its encounter clock. The Elwynn times below belong to the earlier standard-mode capture.

Use the displayed clock, starting with Elwynn

The current Elwynn panel and Drop Tables show Hogger at 3:00, Mother Fang at 6:00, Rhahk’Zor at 9:00, Mr. Smite at 12:00 and final boss Edwin VanCleef at 16:00. Arrival time is not a guaranteed kill or finish time. We have not independently captured every later-zone timer, so this page does not turn community 16/18/20-minute summaries into universal schedules.[1]

When progress looks stuck

  1. Recheck the class on the picker and its Zones open count.
  2. Read the locked zone’s named predecessor and boss. Surviving part of the previous zone is not the same as defeating its final boss.
  3. If the next step feels too hard, inspect class talent points, worn gear and the current build trigger before raising difficulty.
  4. For loot, choose the relevant Drop Tables row instead of assuming the newest unlocked zone drops every missing piece.
  5. In co-op, check that the selected class qualifies for the host’s zone; a code does not transfer another class’s progression.

Separate a zone unlock, a Heroic unlock and a gear-star permission in your notes. Read the difficulty scopes →[1]

Prepare for an encounter instead of only watching the timer

  1. Check the selected class, zone eligibility and difficulty first.
  2. Use the original Elwynn clock above to plan a pause in shopping or drafting before the next arrival.
  3. If a piece is missing, inspect Armory → Drop Tables for this class and target the listed encounter.
  4. If a run fails, use Death Recap to separate incoming avoidable damage from outgoing damage.
  5. Compare one change at the same investment before treating a different zone or Heroic tier as the cure.

An equipment target in Gates of Ahn’Qiraj

The Mage Frostfire Circlet and Warlock Plagueheart Circlet panels inspected in original v0.139.2 both list Kurinnaxx in Gates of Ahn’Qiraj. Use the class-specific Collection or Drop Tables panel to confirm your target and access before starting. This lookup does not establish that the piece will drop on your next run.[1]
