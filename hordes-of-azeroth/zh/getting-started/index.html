Hordes of Azeroth 中文入门与客户端选择

先确认作者 jonhaldors 和仓库 hordes-of-azeroth，再准备独立的 WoW 1.12.1、build 5875、enUS 英语客户端文件。从作者 GitHub Releases 获取对应启动器，放在 WoW.exe 旁安装。中文界面与底层客户端文件语言是两项需要分别核对的条件。

Megabonk.org 编辑 · 核查于 2026年11月5日 · v0.6.4文档与署名玩家报告，未安装客户端

本页目录先认游戏客户端条件安装顺序报错与求助

先用作者与仓库辨认游戏

玩家使用过“艾泽拉斯之潮”等名称，中文名曾在 issue #16 中引发辨认讨论。请核对 jonhaldors/hordes-of-azeroth。它是在本机运行客户端和服务器的幸存者类同人游戏，自动释放技能、升级时选择强化，并在局外继续成长。

作者 README 明确说明，hordes-of-azeroth.com 与作者没有关联。下载应从 GitHub · 作者发行页 ↗ 核对。本站根据作者文档与公开玩家报告整理入口，游戏文件由对应项目提供。

Aethus 的 Azeroth Survivors 使用 wow.aethus.pl 入口。两款游戏都出现魔兽职业名，但操作、构筑和存档需要各自的说明。按浏览器、本地安装、合作人数和存档选择游戏 →

中文界面、文件语言与版本分别检查

检查项当前作者文档要求如何用于选择
客户端版本WoW 1.12.1，build 5875已有 1.14.2 或现代 Classic 文件时，先核对作者支持清单。
游戏数据语言English，enUS中文界面不自动建立其他地区客户端文件的兼容性。
文件夹为 Hordes 单独保留一份保留其他游戏与既有存档，再安装本项目文件。
系统Windows 10/11 64位；Linux / Steam Deck 为 betaMac 当前不在作者支持范围，社区 Wine 报告有额外限制。

issue #32 中有玩家询问能否换用 1.14.2。当前 README 仍列上表条件，因此本页按明确列出的版本给出起步路径。issue #22 的语言/字体报错由作者标为 0.6.2 Hotfix 1 修复，这条修复记录只对应当时的具体错误。

下图来自作者早期 0.1 演示，能辨认 Hordes 的英文关卡选择界面。它用于识别游戏和界面语言，当前平台与合作说明以本页核对的 v0.6.4 文档为准。

从正确文件夹开始安装

  1. 确认所需版本、build 和数据语言，准备专用客户端文件夹，先保留既有进度备份。
  2. 打开 GitHub · jonhaldors 发行页。Windows 选择 HoALauncher.exe；Linux / Steam Deck 选择 HoALauncher-linux.tar.gz。
  3. 将启动器放在 WoW.exe 旁。Linux 压缩包先解压到同一位置。
  4. 运行启动器并选择 Install，等待各安装阶段结束。角色与资源文件未核对前，保留原来的独立文件夹。
  5. 以后从启动器选择 Play。Steam Deck 按作者说明将 HoALauncher 添加为非 Steam 游戏。

当前常规角色文档支持最多 4 人合作。主机从角色界面建立游戏，其他玩家通过列表或代码加入；v0.6.4 的 Hardcore 角色暂时不能合作。单人离线使用需先完成安装，在线更新需要网络。

本页完成了文档与公开报告核对，尚无本站客户端安装、真机、合作联通或完整通关实测。

按具体报错进入下一步

数据库启动失败、下载缓慢和 Wine 缺库是不同问题。保留当前阶段、精确错误、系统、客户端语言与补丁版本，再使用 Report a bug 或启动器 ⋯ → Save logs to the desktop 导出日志。分享前检查日志内容。

查看安装故障分流与署名玩家报告 →。该页保留成功与失败个案，例如换盘帮助过一位玩家，也未解决另一位玩家的问题。已有进度时先保留数据库和备份，再向项目确认涉及数据替换的操作。

项目支持入口为 GitHub · Hordes 问题区 ↗ 与 Discord · 作者社区 ↗。如果希望直接在手机浏览器尝试另一款游戏，可查看 Aethus 原作的设备说明，并保留原游戏的独立存档。
