How to start your first run

  1. Press Play PokeBonk, then choose Play as a guest! in the game.
  2. Select a starter and confirm the button naming that partner.
  3. From the main menu, choose Play. In the League, confirm the Pokémon with I choose you!
  4. Choose Viridian Forest and Normal, then press Start!
  5. Keep moving and gather experience. When an upgrade appears, read whether it changes an owned move, adds a new attack or improves a stat.

We checked this Guest-to-run route in the host’s v0.8.27 on October 26, 2026, and reached Viridian Forest, Zone 1/3. This was a startup check, not a completed run or a performance benchmark.[1]

For more detail, see the beginner guide. Its newer-build menus can differ from this hosted version.

Keep the game and your guide handy

Click inside the game to give it keyboard focus. Use its Settings → Controls screen to check or change the keys for this version.

  • Expand gives the game more browser space. Exit expanded view returns to the page.
  • Minimize folds the game away while you read. The Restore game button stays at the bottom of the screen.
  • Restore keeps the same frame loaded; it does not deliberately refresh the game.
  • Pause inside the game first. Our window controls cannot pause a cross-origin game for you.

Choose a starter by what you want to learn

The checked entry screen offers Bulbasaur, Charmander and Squirtle. Read the selected partner’s actual passive before confirming.

  • Bulbasaur: its Healer role is a starting point for learning recovery.
  • Charmander: its Fire-focused role is a starting point for learning offensive choices.
  • Squirtle: its Defender role is a starting point for learning defensive positioning.

These are role-based directions, not a measured strongest-starter ranking. Our starter comparison, evolution guide and build planner guide cover newer checked beta builds; use this game’s displayed values if they differ.[1]
