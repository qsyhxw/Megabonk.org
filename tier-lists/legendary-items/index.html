Quick Answer

Overpowered Lamp is the leading proc pick when a loadout already has supported on-hit effects. Anvil, Pot, Joe's Dagger and Sucky Magnet become exceptional when the run matches their scaling condition. A lower-rarity item can still be the correct choice if it completes your build.

How This Ranking Works

Tier measures general run value, not a mandatory pick order. The rating combines immediate impact, late-run scaling, trigger reliability, build coverage and how late the item can appear before its effect loses value.

S — Build Defining

High ceiling with reliable value in the right route.

A — Strong

Excellent effects with narrower build or timing requirements.

B — Conditional

Useful when the trigger solves a specific problem.

U — Unranked

No dependable power value for route planning.

Choose by Build, Not Color

Proc / Multi-hit

Overpowered Lamp and Lightning Orb reward frequent hits. Take the Lamp only when supported on-hit effects are already part of the route.

Long Run / Leaderboard

Joe's Dagger, Anvil, Pot, Sucky Magnet and Soul Harvester improve with kills, levels, XP retention or run length.

Poison

Snek supplies Poison stacks and burst potential. Dragonfire belongs to Fire routes instead of being forced into Poison.

Sustain

Holy Book fits healing-heavy setups. Za Warudo is emergency insurance rather than ongoing sustain.

Bloodmark

Bloody Cleaver is a specialist Vlad and Bloodmark choice, not a universal damage pickup.

Short Stage Clear

Prefer immediate effects. Late Anvil, Pot or Joe's Dagger may not have enough time to repay the pickup.

Legendary Drops and Luck

Luck can improve rarity outcomes, but it does not guarantee a Legendary roll or a particular item. The exact chest formula is not available in published patch notes, so this page does not publish a fixed drop percentage or a minimum-Luck requirement.

Unlocking an item and seeing it during a run are separate steps. Check the item detail page for its prerequisite, then make sure it is available in your active item pool.

Legendary Items FAQ

What is the best Legendary item in Megabonk?

Overpowered Lamp is a leading proc pick when supported on-hit effects are already online. Anvil, Pot, Joe's Dagger and Sucky Magnet can be stronger in longer specialized runs.

Are Legendary items always better than Epic items?

No. Rarity affects availability, not whether an effect solves the current build's problem. A matching Epic can be more useful than an unrelated Legendary.

Does Luck guarantee Legendary items?

No. Luck can improve rarity outcomes, but it does not guarantee a Legendary or a specific item.

Why is Golden Ring unranked?

Its description says it does not seem to do anything, so it is not treated as dependable build power.
