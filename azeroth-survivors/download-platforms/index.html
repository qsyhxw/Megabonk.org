Choose a source before choosing a workaround

  1. Export your existing save from the client where it still exists.
  2. For browser play, open Aethus · original browser game ↗ (external website, opens in a new tab) directly and let its data download finish.
  3. For Windows, follow Aethus · Windows archive ↗ (external website, opens in a new tab) from the original host. Extract the complete archive, keeping the executable and Data folder together.
  4. Check the displayed game version after opening it. Do not assume the archive matches the current browser patch.
  5. For other packages or a slow source, check the creator-linked community. A player-shared mirror or lookalike domain is not independently authenticated by its filename.

We did not download and execute the Windows package or certify a checksum. A community GitHub reconstruction is a different project; it is not a transparent substitute for the original save and rules.[1]

Steam Deck: mo7233’s reported Windows route

  1. In Desktop Mode, extract the Windows archive with its full Data folder beside AzerothSurvivors.exe.
  2. Add the executable as a non-Steam game and check Start In points to its folder.
  3. The author reports selecting Proton Experimental.
  4. For the launch crash they encountered, the author reports using WGPU_BACKEND=vulkan %command% in launch options. Treat it as a conditional workaround, not a required flag for every build.
  5. If it starts, check movement, camera and upgrade selection before importing important progress.

Source: Reddit user mo7233, thread read 30 October 2026; exact executable version unspecified. We have not reproduced this on a physical Steam Deck or benchmarked it. Later comments mention a Linux package on Discord; its link and current authenticity were not verified here. [4]

VirusTotal: a report is about a specific submitted item

For a game download, first identify the original source and the exact file or hash a report describes. A scan of a website URL is not an analysis of every executable that website can serve, and a report for an older archive does not establish the contents of a new one. We have not submitted or scanned an Azeroth Survivors package. [5]

VirusTotal aggregates participating vendors’ results, including possible false positives. A detection deserves investigation; it is not something this guide can dismiss as harmless without examining that exact sample. Conversely, a report with no detections is not a security audit or a promise about future downloads. Read the individual labels and date, then ask the detecting vendor about a disputed result. [6]

Public analysis is a sharing service: reports and submitted content can be available to others. Do not upload a personal save, account material or a private file merely to check a game’s name. VirusTotal · official explanation ↗ (external website, opens in a new tab)[5]
