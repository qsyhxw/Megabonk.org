✅ How Verified Megabonk Leaderboard Runs Work

Evidence rules, source ownership and data provenance

Loading current community snapshot…
Verified does not mean official. Megabonk.org uses the independent Leaderboard.gg community dataset because it exposes reviewed runs, video links and complete build data. The board previously used the megabonk.fun address and now operates at megabonk.leaderboard.gg. Steam also supports in-game leaderboards, but there is no separate official public web dataset used by this site.

📊Two Different Trust Models

🎮

Steam In-Game Leaderboard

Developer Supported
Accessed through the game and Steam integration. It is not the public build-data source mirrored here.
  • Game-controlled score upload
  • No public build JSON used here
  • May reset after balance changes
📹

Leaderboard.gg Community Board

Video Reviewed
Independent public leaderboard with full-run video requirements and visible build details. It is not affiliated with vedinad.
  • Complete run video and final score required
  • No mods, exploits or hacking
  • One displayed run per player per character
  • Patch-specific filters

🔍What “Verified” Means Here

ℹ️Mirrored source status
A verified record on this site is an approved record present in the Leaderboard.gg dataset. Megabonk.org does not independently watch and certify every video and cannot approve, deny or remove submissions.

🛡️Current Submission Requirements

  • Show the entire run from start to finish.
  • Include a clear final score screen.
  • Use the patch currently accepted by the board.
  • Do not use mods, hacking, exploits or edited footage.
  • Keep the submitted video accessible for review.

❓Frequently Asked Questions

Is Leaderboard.gg official?▼
No. It is an independent community leaderboard and states it is not affiliated with vedinad.
Why use it instead of Steam data?▼
It provides a public structured dataset with videos, characters, equipment and timestamps. Steam’s in-game board is not a comparable public build feed.
Can a verified run still contain a mistake?▼
Community review reduces risk but is not an absolute guarantee. Check the linked source video when a result looks unusual.
Where do I submit or appeal?▼
Use the Submit or contact controls on Leaderboard.gg. Megabonk.org cannot modify source submissions.
