Cross-platform and online questions

Brotato has no built-in online matchmaking in the sources we checked, so cross-platform online play with strangers or across PC and console is not a supported route. On PC, Steam Remote Play Together is the way to play with friends elsewhere: one host runs the game and guests join through the Steam invite. Console copies stay on local co-op unless a platform announces a feature. Remote play quality depends on the host connection, so test a short session first. Community reports also describe lag and input problems, so treat them as a reason to check your setup rather than a guaranteed result. Brotato Steam features and Valve’s Remote Play guide are the sources for the Steam routes.

Set up Remote Play Together

  1. The host launches the installed Steam game.
  2. Invite the guest using Remote Play Together in the Steam friends list or overlay.
  3. The guest accepts. Check allowed controller and keyboard inputs.
  4. Join the local session and confirm each player controls a different character before starting.

Valve documents one owner running the game while guests receive video and return inputs. The host computer and connection remain involved.

If inputs or crates fail

When two people control one character, check Remote Play input permissions and local device assignment separately. Establish that controllers work locally before blaming the connection.

After an update, reproduce crashes without mods. The November 3 patch includes a Survivor co-op crate fix. The 12 November default-branch patch fixes the Mecha Parts counter blocking co-op shop and inventory navigation. Match the symptom and branch before assuming a particular issue is fixed. Official patch notes

Check weapon-popup navigation after updating

The 12 November default-branch patch fixes controller navigation getting stuck in a weapon popup when buttons are hidden. Hotfix 1.2.0.3 also fixes the missing gamepad selection after buying an item while the mouse cursor rests on another shop item. Check the installed branch when matching this symptom to a patch note. 12 November balance notes

Check the session before a long run

Agree on host, inputs and enabled content. Start a short unmodded session to verify controls. For mod conflicts, use the compatibility checklist.
