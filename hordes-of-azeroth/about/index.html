About the Hordes of Azeroth guide

Megabonk.org editors · Facts reviewed 5 November 2026

Who runs this section

This is an unofficial fan guide published by the editors of Megabonk.org, an independent site for survivors-style games. We are not jonhaldors, who makes Hordes of Azeroth, and we are not Blizzard Entertainment, which owns World of Warcraft; nothing here is an official announcement.

What it covers

The section answers the questions that come before and during a first install: which client files the install and platform page expects, how to pick between this project and Aethus's browser game in the comparison, how to find the failing stage in installation troubleshooting, and a Chinese start page at 中文入门.

It does not rank classes or publish builds for this game.

Where the answers come from

  • The author's repository: the README ↗ (opens in a new tab) supplies the client build, disk space, platforms, install steps and co-op rules; the releases page ↗ (opens in a new tab) supplies the launcher files and version notes.
  • Named public reports: GitHub issues and launch threads supply the installation symptoms and the Mac / Wine report, each limited to what its reporter described.
  • Author gameplay footage: screenshots are frames from the author's own recording and a reported error screen. We have not installed the client or played a run, and the pages do not claim to.

How pages stay current

Each guide shows the date it was checked, currently 5 November 2026, against version 0.6.4. When the author publishes a new release, the pages that depend on its requirements, platform list or co-op rules are rechecked first.

Which game is this?

Searches for the name also return similarly named websites and Azeroth Survivors. This guide follows jonhaldors's repository only; the author states that the hordes-of-azeroth.com website is not run by him.

Found something wrong?

Send the page URL, your operating system, the launcher version and what you saw through the contact page. Corrections backed by a screenshot or the author's own statement are usually applied in the next update.
