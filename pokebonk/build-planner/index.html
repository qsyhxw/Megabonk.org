Plan moves, check pairs and budget the slots

Choose a partner, select its actual listed moves, then check eligible pairs and remaining capacity. A fusion needs both ingredients at level 8 and frees one slot. This tool checks a plan, not DPS, ownership or guaranteed offers.[1]

Use a goal, then keep a fallback

Survival: compare move class/type and whether you can keep hitting while moving. Fix the last failure before chasing a late pair. Fusion: reserve two ingredient slots; do not assume a fourth move is free. Status: read the actual source of the required status; type alone does not establish applications.

The planner uses the partner’s listed kit. It does not model Mew’s broader pool, later evolution-specific offers, items, archived choices or shared game progress. An unmatched pair uses the fallback rule; a recipe match still requires the actual machine and eligible moves. Share links contain only the version, partner, selected moves, capacity and goal. They do not log in, upload a save or change the game.
