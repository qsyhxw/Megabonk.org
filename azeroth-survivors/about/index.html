About the Azeroth Survivors guides

Megabonk.org editors · Reviewed 16 November 2026 · Original v0.145.0

Game data checked against the latest original client · What changed

Who writes these guides

This is an unofficial fan guide written by the editors of Megabonk.org, an independent site for survivors-style games. We are not Aethus, the creator of Azeroth Survivors, and we are not Blizzard Entertainment. Nothing here is an official announcement or game support. Class, spell and item names and icons belong to their owners and are shown to identify what each guide talks about.

What the section covers

The guides answer the questions players hit between runs: which talent route to build for each class, where each class sits on the tier list, how talent points and gates work, how to plan points in the build planner, which zone and boss opens the next area, how co-op rooms work, and how to back up a save or fix a game that will not load.

Where the answers come from

  • The original game: class, talent, race and zone text is read from the original client at wow.aethus.pl as data, without running modified files. Talent menus, the Armory and the character screen are captured from the game itself; screenshots on each page say which version they show.
  • Community rankings: the tier list averages three public class rankings and shows each source’s vote, so you can see where they disagree.
  • The creator’s channels: download links and the community invite are the ones linked from the original launcher.

When sources disagree, the page gives the answer the current client text supports and says which version it applies to.

How pages stay current

A monitor reads the original client every six hours. The latest detected version is v0.145.0 (2026-11-16). When names, races or links change, the affected reference tables update automatically; when talents or mechanics change, the guides that depend on them show a status line until an editor rechecks them. See the version status page for what changed.

Which game did you mean?

Looking for the Warcraft-themed game with automatic spells? This guide covers Aethus’s Azeroth Survivors at Aethus · original browser game. Descriptions such as “WoW roguelike”, “WoW Vampire Survivors” or “WoW Megabonk” can point to this style of game; they do not make it Blizzard’s World of Warcraft, Vampire Survivors or Megabonk itself. Choose the actual game and host before using a build or moving a save.

Is Azeroth Survivors made with AI?

As of 5 November 2026, we have not found a verifiable statement from Aethus identifying which AI tools, if any, were used to develop the original game. Community descriptions such as “vibe coded” remain claims. A separate author’s reconstruction or another WoW project cannot establish the original creator’s workflow. The visible game credit identifies Aethus; it does not document development tools. See the captured creator credit.

The community rebuild README (GitHub · community reconstruction) identifies a separate local build and points to the original. This is an entity check, not evidence for an AI-generated percentage or a statement that the original used no AI.

Looking for WoW Forever name reservation? That belongs to Blizzard’s separate game. Use Blizzard · reservation instructions and eligibility for the account requirements and regional schedule; the Aethus browser entry does not reserve those names. Checked 2 November 2026. (Blizzard · Forever character-name reservation)
