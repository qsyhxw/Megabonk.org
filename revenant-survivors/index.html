How worlds and Hard levels unlock

From the 0.6.4 announcement (16 November 2026). The Hard Mode guide has the rewards.

Clear World 1–6
The next world, on a random map each time
Clear World 7
Hard 0 in every world
Clear Hard N in any world
Hard N+1 in all worlds, up to Hard 10
Mythic gear
Drops at Hard levels and is guaranteed at high ones; Magic Find raises the odds

Common questions

Does my Revenant Survivors Demo progress carry into the full game?

Yes. The developer confirmed it. Launch the full game first on the PC that holds the Demo save, check the imported progress, then let Steam Cloud finish syncing before using another PC.

Full answer →
How do I unlock Hard Mode in Revenant Survivors?

Since update 0.6.4, clear Worlds 1–7 in order. Clearing World 7 unlocks Hard 0 in every world, and each Hard level you clear unlocks the next one up to Hard 10.

Full answer →
What carries over between runs?

Equipment, Forge upgrades, Skill Trees, Soul Engraving and the Armory are permanent. Equipped gear does not change how your character looks.

Full answer →
Which world should I farm for Mythic gear?

Each of Worlds 1–6 drops its own Mythic set; World 7 drops Mythic gear outside the sets. Difficulty and rewards match across worlds at the same Hard level, so farm the set you want.

Full answer →
Why is the game stuck after a run ends?

Update the edition you launched, then match where it stops to a reported fix: a launch skin-DLC scene-loading fix, a return-to-village loading fix, or a Demo crash fixed in 0.3.1.
