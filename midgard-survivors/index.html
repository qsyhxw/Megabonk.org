Start a first run

  1. Choose a class and enter a field. Attacks fire automatically.
  2. Move with WASD, arrow keys or click. Pick level-up offers with 1, 2, 3 or click.
  3. Use Q for equipment, C for status, I for inventory and Esc to pause. Right-click moves the camera. F manages disabling some skills.
  4. Watch for the MVP alert and portal at the end of a map, then review the retained equipment before another attempt.

These controls come from the itch.io listing. It describes a second-job choice at Base Level 20. Confirm the choices offered in your installed build before planning a class route.
