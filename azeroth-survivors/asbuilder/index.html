ASBuilder for Azeroth Survivors

ASBuilder is Cadoky’s Azeroth Survivors planning tool. Its online version at asbuilds.app lets you choose a class, arrange spells and jewelry by stage, edit talents and keep a browser draft. The separate addon displays planned choices during a run. ASBuilds.app · open ASBuilder online ↗ (external website, opens in a new tab) · Use our Mage & Warlock talent planner here →[1][2]

Create an ASBuilder plan online

  1. Open ASBuilds.app. Dismiss the first-use tour with Skip, or follow its four screens. Choose a class and enter a Build name. Use + New build when you want another draft.
  2. In Loadout, choose Early Game, Mid Game, End Game or Endless. These stage names can be changed. Click a spell icon to add it, set its target rank and move it into priority order.
  3. Choose Rings, Trinkets and Amulet in the picker. The web layout offers two main rings and two alternatives, two main trinkets and two alternatives, and one main amulet with three alternatives. Alternatives are fallback choices, rather than extra worn slots.
  4. Move to the next stage. Copy previous carries the earlier picks forward so you can adjust the next targets. Record a reason for changing spells or jewelry in Notes.
  5. Use Talents to inspect the class tree and Armory for pre-run equipment. Check the corresponding rules in your current game before following the finished plan.
  6. Click Save after editing. Reload and confirm the intended class, stage and entries remain before closing the tab. Keep an export as a separate backup.

Our 4 November check completed these loadout choices, stage copying, explicit saving and reload recovery in a desktop Chrome session. The same plan was viewed at a 390-pixel mobile width. Talent allocation accuracy, physical-phone input and game-side use were outside this check. [1]

Copy, import and back up a build

  1. Copy code exports the selected build as an ASB2 code. Keep the complete string together with your game version and a short note about the plan.
  2. Import code accepts an ASB2 build or an ASBP whole-profile code in the web interface. Our ASB2 check added another build to the list. Inspect the imported class, stages and picks before editing.
  3. Copy whole profile is the separate backup route for the browser’s collection of plans. A profile import can merge plans, so check the list afterward.
  4. Share publicly uses a separate account/publication flow. Review notes and image links before choosing publication. We checked local code sharing without creating an account or publishing a build.

The ASB2 round trip was verified between two states of the web planner. Import into the game addon still needs a client-specific check. Game progress is backed up through the game’s own save export →. Our on-site talent planner uses its own link and JSON format. [1][2]

Use the addon with the right client

GitHub · Cadoky’s latest ASBuilder addon ↗ (external website, opens in a new tab) is the author’s download route. The README places the ASBuilder folder inside benilla-config/AddOns/, then restarts the game and opens the planner with /asb or its book button. [2]

For the browser client, follow Options → AddOns → Install AddOns → and check the package in that client. The original AddOns capture documents that dated interface. We have not installed ASBuilder there or confirmed its current import behaviour.

The author describes an in-run tracker and stage targets. Its README says the addon cannot read game talent data and instead supports a talent screenshot link. The online Talents editor is a separate feature visible on the web tool. [2][1]

ASBuilder questions

Do I need the addon to plan online?

The web loadout flow worked without an addon installation or account in our check. The addon is the route for displaying the plan during a game run. [1][2]

Where are my private plans saved?

The web interface stores plans in the current browser. Use its Save and export controls before clearing site data or changing device. Public sharing is a separate action. [1]

Does a code prove that the build works on the latest patch?

A successful import confirms that the planner could read the code. Check talents, spell effects and item previews against the current game before applying it. Check our original-client version record → · Match the jewelry name and icon →[1]
