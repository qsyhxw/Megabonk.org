Revenant Survivors demo save transfer to Early Access

Demo progress can carry into the full game. For the first full-game launch, use the PC that still holds your demo save. Confirm the imported progress, close the game and let Steam Cloud finish syncing before moving to another PC on the same Steam account.

First launch on the PC with your demo save

A Steam player asked whether Demo progress would transfer to Early Access. The developer confirmed it on October 26 and supplied the first-launch and Cloud sequence in the November 9 release announcement. Developer confirmation of Demo transfer · Launch instructions for save transfer

  1. Use the PC where you played the Demo and still have its local save data.
  2. Launch the full game there for the first time.
  3. Inspect recognizable progress, such as your unlocked content and permanent-upgrade panels, before continuing.
  4. Once the transfer looks correct, close the full game normally.
  5. Wait for Steam Cloud to finish syncing the full-game save.

Continue on another PC

After the first successful transfer, sign into the same Steam account on the other PC. Enable Steam Cloud on each PC and wait for syncing to finish before starting the full game. This is the sequence specified in the release announcement.

The first local import and subsequent full-game Cloud synchronization are two consecutive steps. If you already opened the full game elsewhere and the expected progress is missing, return to checking which PC holds the Demo data before attempting further transfers.

If expected progress is missing

  1. Record which PC contains the Demo save and where the full game was first launched.
  2. Check the Steam account and Cloud status on both PCs.
  3. Capture the full-game progress screen showing the discrepancy and record the installed version.
  4. Send those details through the game’s Steam Discussions. The developer requests reports when transfer fails.

The reviewed instructions do not specify a manual file-copy path, recovery command or cross-store transfer procedure. A failed import therefore needs a report with the launch sequence and account details relevant to the issue. Keep passwords out of public reports. This guide follows the developer’s procedure and has no independent save-transfer test.
