How to Read the Tiers

S

Exceptional

Strong, consistent choices that shape high-performing builds in the list's stated mode and patch.

A

Strong

Reliable choices with clear strengths and only modest tradeoffs.

B

Viable

Useful choices that need the right build, route or player execution.

C

Situational

Narrow choices that can work but are less consistent or more demanding.

How Rankings and Meta Data Are Evaluated

Editorial tier placement

Detailed lists weigh consistency, scaling, opportunity cost, build compatibility and mode-specific performance. Rankings do not change automatically from one usage snapshot.

Patch facts

Effects, unlocks and balance changes are checked against the site's latest tracked patch notes. Each category page states its own review baseline.

Leaderboard usage

The automated panel counts appearances in the current ranked-run sample. It shows what successful submitted runs used, not what every player must choose.

Version guard

If the leaderboard version differs from the latest official patch, the page labels the mismatch and keeps that evidence separate from current-patch editorial conclusions.

For a specific entity's effect or unlock, use the database. For comparative recommendations, use the matching tier list. For complete ranked loadouts, use the leaderboard builds page.

Frequently Asked Questions

What is the best character in Megabonk?
There is no single best character for every mode and build. Use the Character Tier List for current editorial placements, then check the linked character guide and build page for your preferred role.
How often are Megabonk tier lists updated?
Each detailed list has its own editorial review date. The ranked-run usage panel refreshes when the scheduled leaderboard sync succeeds, and it always displays the source game version and snapshot date.
Does high leaderboard usage mean an automatic S-tier ranking?
No. Usage shows what appeared in a limited group of successful submitted runs. Availability, one popular strategy and version differences can all affect the rate, so it is supporting evidence rather than an automatic tier.
Should casual players follow the current meta?
Use the lists to avoid weak combinations, but prioritize a character and build that fit how you play. A lower-ranked option can still be the better choice when its mechanics match your route or comfort level.
