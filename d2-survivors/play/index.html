From the title screen to your first run

  1. Click Play above and allow the game resources to finish loading. Click the title screen when prompted.
  2. Choose Play, then a hero using the selection shown by this edition. Read the offered skill cards as you level.
  3. Move with WASD. Skills attack automatically; use Esc for the pause menu. Click inside the game if movement keys reach the page instead.
  4. Use the game’s save-and-exit option before leaving. Open SAVES on its main menu to keep a backup where available.

Expand creates more room. Hide and Return preserve the same game frame; hiding is not pausing. Pause inside the game before reading another guide. Closing this page ends the embedded session. [1]

If the window does not start

Wait for the game’s title/menu rather than treating a loaded frame as a successful start. If it stays blank, open d2survivors.org · same edition in a new tab ↗. Keep a note of the host, displayed version and exact message; do not clear saved site data as your first attempt.

Use a desktop or laptop with a keyboard for this route. The current original FAQ says phones are not supported; a phone-sized page check does not establish game compatibility. [2] The original also blocks third-party framing, so its link opens externally. We do not proxy it or remove its restrictions.

This game host and any services it loads control their own data and progress. We cannot read or recover that cross-origin storage. Read the game-window privacy notice.
