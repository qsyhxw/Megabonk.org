Rest an unwanted skill or rebuild the Druid?

Resting stops a skill from casting while retaining its slot; it is not a respec. For a rebuild, the current original reference describes Akara’s Re-draft after that hero’s first Baal kill. Neither is a verified instant fix for every historical shapeshift report.

Megabonk.org editors · Checked 3 November 2026 · Original references and dated interface captures; no complete-run or save-migration test.

First decide what you want to change

Want to stop an unwanted cast? The current original reference says to right-click the skill slot during a run to rest it, and repeat to enable it again. The slot and learned level remain. Want to choose a different set of skills? That requires a re-draft route rather than resting every skill. [1]

Old community replies suggested resting Werewolf/Werebear when an elemental Druid was disrupted. Those are historical reports; preventing another cast and ending a transformation already active are different claims. We have not reproduced that bug or certified a universal fix. [4][3]

Check Akara’s condition before planning a reset

The current camp reference locks Re-draft and Start over until the hero’s first Baal kill. Read the option you are confirming: re-drafting skills and returning to level 1 are distinct choices, with confirmation steps. Back up first, and inspect any saved-run warning. These instructions describe the reference’s camp version; do not search an older class-selector release for a feature it lacks. [2]

If the expected skill still will not cast

Record your host and displayed build, learned skills, active form and whether the skill is rested. Then check the skill’s actual targeting and form rules in that version. Avoid resetting the character just to test whether a button is hidden. Preserve the save before reporting the symptom. This task guide does not rank the best Druid build or promise that all elemental skills behave alike.
