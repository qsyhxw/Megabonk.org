Check the build you actually have

Match the buff to the move’s damage category: Swords Dance boosts physical attacks; Nasty Plot boosts special attacks. Then check which group is active and which moves are linked by Bonds. A high overall stat does not make every move equally strong.

A move’s elemental type and physical/special category are separate. A Psychic-type partner does not make every learned move special, and the displayed atk field is the larger of pa/sa, not a universal damage multiplier for any move.

For a Mewtwo using Psychic and Confusion, inspect their special category before copying a Swords Dance recommendation. The current source assigns the buff effects separately.

Why an older recommendation can mislead

In a Reddit question read October 26, JeoYu asked why videos used Swords Dance with Mewtwo’s Psychic/Confusion. One visible commenter reported trying the buffs and seeing only Nasty Plot affect that setup; another explained that older versions lacked the split. Those are their reports, not our tests.

Before following a clip, write down the game address, version and exact moves. If the clip predates a mechanics change or comes from a native port, copying the same four names is not enough. Use the current move category as the first check rather than treating view count as performance evidence.

Slots, active groups and Bonds

  1. Check the selected slot. Automatic attack normally uses the active move; unselected moves are not automatically simultaneous attacks.
  2. Read the slot contents. A Bond joins attacks into one slot/group, allowing those linked moves to act together.
  3. Count the Bonds you actually earned. A planned four-move group is not available just because all four moves are learned.
  4. Leave room for a damaging attack. Selecting an unlinked buff changes what is active; inspect the UI rather than assuming the whole loadout attacks.

The reviewed level-up logic stops offering further new buff moves once you have two. That offer rule is separate from permanent upgrades, the number of ordinary slots and any particular recipe.

Before teaching a TM or paying for a route

The creator’s guide describes TMs as permanent teaching for eligible partners. Check the partner name, legal move and physical/special fit before applying one. A move being teachable does not establish that it solves the build’s current problem.

Two different authors requested a way to forget an accidentally taught TM in issues #348 and #343. These are requests, not proof of an undo feature. We have not verified a refund or forgetting route; preserve that limitation before spending.

For run evolution, check the required card in the upgrade explanation. A permanent stat investment does not establish the run prerequisite.
