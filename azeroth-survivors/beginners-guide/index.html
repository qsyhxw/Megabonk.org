Start your first Azeroth Survivors run

Open wow.aethus.pl in a WebGPU-capable browser. Pick a hero, move while spells attack automatically, and choose upgrades when the card offer appears. Keep the cards for this run separate from the talents and equipment you develop between runs.

From the original page to a run

Need a route into the game? Check the third-party edition → or find the original Windows download →. The steps below describe the original host; check the edition before following them.

  1. Open Aethus’s original game ↗ (external website, opens in a new tab). Keep this guide in a separate tab. The original does not run inside this website.
  2. Allow the initial game-data download to finish. A loading bar is different from a WebGPU warning or a server quota message.
  3. Choose your hero and inspect the class, selected talents and starting spell. A developed character may start with a different spell from a new one.
  4. Start the run with Enter. Move to leave room around the hero, collect experience and read the offered upgrade’s effect before selecting it.
  5. When the run ends, inspect permanent progress and prepare the next attempt. Export a save before changing browser, device or host.

If the game has not reached the hero picker, check WebGPU and adapter availability → or match the message you see →. The browser check does not test the game server. Keep your existing save before changing host or clearing storage.

Controller settings: check input before a long run

Open Options → Gamepad. The original v0.130.0 menu inspected on 30 October 2026 shows camera inversion, camera speed, zoom speed and stick dead zone. Its on-screen hint maps the left stick to movement, right stick to the view, A to jump, bumpers/triggers to zoom and Y to stored level-ups. This is menu evidence, not a controller compatibility test.

  1. Confirm movement and camera input in a short attempt before importing your only save.
  2. If the camera direction feels wrong, change the corresponding inversion setting.
  3. If the stick drifts, adjust the dead zone and check again; do not assume the displayed default suits every controller.
  4. Keep a keyboard or other working input available until you have checked menus and upgrade selection.

A Steam Deck report does not establish that every controller or browser exposes the same inputs. Read the Steam Deck evidence boundary →

Gear will not upgrade: marks, stars or the wrong item?

For permanent gear, open the Armory from the hero picker, choose the class and inspect the piece in Collection. Use the piece’s displayed Upgrade control and cost rather than a price from another class or version. The following decision order is based on original v0.127.0 interface text inspected 29 October 2026; it has not been replayed in v0.130.0.

What you seeWhat to check next
Nothing worn adds bonusesFind class gear from the bosses shown for the piece; starting clothes are not upgraded boss gear.
LOOK rather than equipped gearRight-click equips/unequips; Shift+Right-click chooses the appearance. A look alone adds no gear bonus.
Not enough marksCompare that class’s marks with the cost displayed on this piece. Do not substitute gold or a cost from another item.
Stars lockedRead the required Heroic level and zones on the piece. The text directs a first unlock to Heroic I in its zones; marks alone do not bypass that condition.
Fully upgradedChoose another piece or improve another constraint; this is not a failed payment.

Make one change, then inspect the worn piece and bonuses before spending more. Four pieces of one set require at least one star each for its four-piece bonus; the eight-piece bonus requires all eight at three stars or above in this inspected version. This is a progression check, not a best-in-slot or farming-rate claim.

Camera distance and controller zoom

The current v0.130.0 Controls text names Max Camera Distance and describes how far the camera may follow behind you. This is a distance limit, not a verified numerical field-of-view setting. The Gamepad panel separately supplies Zoom Speed; bumpers and triggers zoom. If the view is hard to manage, compare distance, follow style and camera speed separately instead of treating them as the same setting.

Open Options → Controls and scroll to the camera controls, then inspect Options → Gamepad for controller settings. We inspected these labels and panels but did not validate a mouse-wheel mapping or physical-controller behaviour; use the current Key Bindings screen to confirm your own binding.
