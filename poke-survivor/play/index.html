Know which edition you are playing.

The embedded game is supplied by pokesurvivor.pro, an independent host.[1] It is not the creator’s original site and its exact parity with the current original build is unverified. Our other guides name the original source version they cover; hosted editions can differ.

On October 26, 2026, our desktop Chrome cross-site check completed guest setup, selected Scorbunny and entered a short run: the timer reached 00:09, movement worked and the defeat counter reached 1. This checks startup, not a complete run, multiplayer, cloud saves or account transfer. Mobile layout checks are browser simulations, not physical-phone benchmarks.

The host labels guest progress as not saved to an account. Keep existing progress at its original address and browser profile. For the creator’s edition, use pokesurvivor.com ↗ (external website, opens in a new tab) instead.[2] We cannot access either provider’s game accounts or recover their saves.
