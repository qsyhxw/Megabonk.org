What the calculator checks

CheckHow to use it
BudgetSet 0–51 points, matching what your character has earned. The cap is shared across the three trees.
Row gatesSpend within the same tree first. A gate at 10, 20 or 30 does not include the additional point buying its node.
Named prerequisitesThe checked rank is required, not just an earlier node name. Legion Gate needs Soul Devourer 3/3 or Soul Link 3/3.
ExclusionsSoul Devourer and Soul Link cannot coexist. Pact of the Nathrezim and Butcher cannot coexist.
RefundsA point can be removed only if every later step remains valid. Remove dependent steps first.

These are original-menu rules observed on 3 November. A valid sequence means the recorded rules passed; it is not a test of actual combat, gear unlocks or every later patch.[1]

Versions, saves and next checks

  1. Compare the version in your game with the planner snapshot. A newer source needs verification before applying an old allocation.
  2. Use the skill and equipment notes to record choices; they do not grant cards, gear or achievements.
  3. Keep a game-save export separately. A planner JSON file cannot be imported as a game save.
  4. Use the original client to inspect your actual ranks and starter after allocating.
