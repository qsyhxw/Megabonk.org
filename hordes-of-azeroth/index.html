Check the client before choosing a download

The author requires your own World of Warcraft 1.12.1, build 5875, English enUS files, in a copy dedicated to Hordes. Keep about 3 GB of free disk space next to the game and use current graphics drivers. That is free storage, rather than a RAM specification.

The launcher and the original WoW client are separate items. The project supplies its own code and reads game assets from the client files you provide. Its author neither supplies nor links the WoW client. Use the listed build when checking your files, including if you already have a modern Classic or 1.14.2 installation.

The author explicitly says hordes-of-azeroth.com is unaffiliated. Establish the download through the jonhaldors repository and its Releases page. A matching domain name alone does not establish that relationship.

From a dedicated folder to the launcher

  1. Keep a separate copy of your compatible client folder. Preserve any existing game progress before changing files.
  2. Open GitHub · author releases. Choose HoALauncher.exe on Windows, or HoALauncher-linux.tar.gz on Linux / Steam Deck.
  3. Place the launcher beside WoW.exe in that dedicated folder. Unpack the Linux archive there.
  4. Open the launcher and press Install. Allow its resource stages to finish. First installation and an update have different work to complete.
  5. Use Play in the launcher thereafter. It manages the local server alongside the game. On Steam Deck, the author says to add HoALauncher as a non-Steam game.

Monster paths normally download ready-made. If that download fails, the launcher can build them locally, using the CPU allocation it asks you to choose. Record the current stage before treating a long wait as a crash. For a stopped update or a database message, follow the symptom checks.

Review the release's own file information and SHA-256 when checking a downloaded launcher. Our review covers documentation and images, with no installed-client, binary-audit or completed-run result established.

Solo or up to four players

The current README documents up to four players. A host opens a game from the character screen; other players find it in the browser or join by code. Characters bring their progress, and earned progress returns with them. The host's PC runs the game. Older launch discussions and guides can still describe solo-only builds.

For a group, check that everyone uses compatible current versions and follows the author's connection instructions. The README distinguishes joining from hosting and explains TCP 3725 when automatic host connectivity fails. In v0.6.4, Hardcore characters cannot play co-op yet. This guide has no verified multiplayer session or port-forwarding test.

Solo play is documented as available offline after installation; update checks need a connection. Keep local progress and the launcher's backups before changing installations. Compare the two games' storage decisions →

FAQ

What do I need to play Hordes of Azeroth?

Your own World of Warcraft 1.12.1 client files, build 5875, English enUS, in a folder kept for Hordes, plus about 3 GB of free disk space. The project does not include the WoW client.

Where do I download the launcher?

From the author's GitHub Releases page: HoALauncher.exe for Windows or HoALauncher-linux.tar.gz for Linux and Steam Deck. A similarly named website is not the author's.

Does Hordes of Azeroth run on Mac?

The author lists Mac as unsupported. One public Apple Silicon report uses Wine and describes three separate failures, so treat it as a bounded workaround rather than a supported route.

Can I play Hordes of Azeroth with friends?

Version 0.6.4 documents up to four players: a host opens a game from the character screen and others join from the game browser or by code. Hardcore characters are excluded from co-op.

Is Hordes of Azeroth the same as Azeroth Survivors?

No. Hordes of Azeroth is jonhaldors's local-client project for WoW 1.12.1; Azeroth Survivors is Aethus's separate browser game. Their setup and saves do not transfer.

About this guide

Hordes of Azeroth is jonhaldors's survivors-style mode for World of Warcraft 1.12.1: spells fire on their own, every level-up offers a choice and the game runs on a small server on your PC.
