Check the Look before repeating the run

Open the selected League member’s Wardrobe and read that exact Look card. Mastery Looks are family-specific challenges; Shiny, Classic Shiny, event Spectral and Treasures Looks use other unlock routes. A Glacier clear or a Burn total alone does not satisfy every skin card.[2]

Checked October 26, 2026 · Beta v0.8.55 · Source-based guide

A stuck-progress checklist

shazamtamp reports Glacier clears without a skin and a Vulpix Burn counter remaining at zero (23h-old post sampled October 26). The report is unresolved: it does not establish that the current patch fixes it or that all skins are bugged.[3]

  1. Write down the exact Look name and selected League family. A win by another family does not automatically count.
  2. Check solo eligibility. The project’s v0.8.42 note says Look challenges count in SOLO. Co-op success is a separate record.
  3. Read every qualifier: victory, Hard/Nightmare, region, final evolution, hits taken, damage-share or status total.
  4. For a status task, confirm actual applications rather than type damage. Use the Sleep/Burn instructions in the unlock guide.
  5. Compare the results screen and Wardrobe after the server accepts the run. Keep screenshots of an apparent mismatch.

For Vulpix Blue Kitsune, use its own Burn requirement and family restriction. Equipping Flame Orb does not guarantee a given count; its chance is only one part of the process. Report a repeatable mismatch to PokeBonk Discord support ↗ (external website, opens in a new tab). No account credentials are needed in a public report.
