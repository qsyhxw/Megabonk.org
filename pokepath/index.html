Open the original PokéPath TD game

Play on the original PokéPath site ↗ (opens in a new tab)

The destination is pokepath.gg/play/ in a new tab. Its page links the current browser client at play.pokepath.gg and the creator’s desktop downloads on itch.io. The original site identifies Khydra as the game developer and Nox as its site maintainer. PokéPath TD is an unofficial Pokémon fan game.

The browser client reached profile creation and the Route 1-1 tutorial during our 9 November check. Choose a profile and starter, then follow that tutorial. A full route clear and save transfer have not been tested here.

Start with device and save setup if you are changing browsers. Use the team guide when you can play but keep losing a wave. For Lunala, read the route-specific shield checks before replacing your whole roster.

Make the first session manageable

  1. Read the starter’s displayed ability. The checked profile screen offers Charmander, Treecko and Froakie. Charmander’s description gives Burn, so it is a straightforward first choice if you want to follow one damage effect while learning placement.
  2. Place for path coverage. Compare where an enemy enters and leaves the attacker’s range. A legal tile with a poor firing window can waste an otherwise useful Pokémon.
  3. Inspect the next wave. Armor and invisibility call for different team jobs. Use the role checklist to decide what is missing.
  4. Back up before a device change. Download an exported save before clearing browser data or moving to another host.

The project introduction ↗ (opens in a new tab) documents persistent Pokémon progress after a defeat, free route switching and Auto Mode for farming. Those features make another attempt productive. For an early session, learn your placement and check a failed wave before leaving automation running.

Match a guide to the current build

The original play page displayed 1.7.2 on 9 November 2026. Its 8 November patch notes ↗ (opens in a new tab) change abilities, item eligibility and several attackers. Check the version on your own host before copying an older team. For example, the update removes Focus Band from Spinda and changes Decidueye’s ability. An older setup depending on either interaction needs another review.

PokéPath is a route tower defense game. PokeBonk, PokéSurvivor, PokéRogue and PokéClicker have separate progression systems. Use More games to select the matching project when a search has brought you to a different game.
