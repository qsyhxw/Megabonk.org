PokéSurvivor multiplayer: co-op with friends

Yes: PokéSurvivor has online co-op for up to 4 players. Everyone needs an account on pokesurvivor.com; add friends in the Friends menu, invite them to a room and the host starts the run. A downed teammate can be revived.

Start a co-op run

  1. Each player signs up on pokesurvivor.com (guests see “Create an account to play with friends”).
  2. Open Friends and add each other.
  3. The host creates a room and invites; wait until everyone is in the room.
  4. The host starts the run. If you go down, you can watch a standing teammate (Q / E) while you wait to be revived; after the run, “Play again” keeps the room together.

Fix lag and stuck rooms

  • Turn on Settings → Graphics → Show ping: green below 100 ms, yellow up to 200 ms, red above. The player with the best connection should host.
  • Lower Quality and set Pokémon effects to “Only my partner” if everyone stutters in big fights.
  • If the host switches tabs or stops responding, the others wait 30 seconds before the run goes on; keep the game tab in front.
  • A host leaving after everyone picked a card no longer freezes the run, and “X is choosing…” stuck screens were fixed on 14 November: reload once if you still see one.
