Brotato Mods After 1.2 — Compatibility Checklist

Reproduce crashes without mods after updating to 1.2. The developer warns that outdated mods can conflict. The optional 1.2.0.4 beta repeats the instruction to deactivate and unsubscribe from all Workshop mods before playing.

Establish the clean baseline

  1. Record version, branch and subscriptions.
  2. Back up your save before changing an experimental setup.
  3. Deactivate mods and restart.
  4. Repeat the failing action with the same character and Item Sets.
  5. Check current patch notes if it still fails.

Developer launch and beta warnings support this first diagnostic step. A continuing unmodded crash needs its own reproduction report.

Restore a compatible setup

Check each author’s supported version, dependencies and recent comments. Restore one compatible mod or required dependency group, restart and repeat the failing action before adding another. Workshop popularity does not establish compatibility.

The 12 November balance changes are released on the Steam default branch. Record your installed version and patch date when comparing a mod author’s supported builds. For the optional 1.2.0.4 beta announced on 17 November, deactivate and unsubscribe from all Workshop mods; the developer warns that outdated mods may cause crashes and corrupted saves. Back up the save before switching, then follow the official beta instructions. If a required mod supports only the default branch, use that supported environment.

Check whether a multiplayer mod is needed

Steam lists local co-op and Remote Play Together. Older loader tutorials may predate those features. For a normal run with friends, use the supported co-op setup first. Identify the extra feature you need before choosing a mod.

When the clean game still crashes

Compare the exact action against the November 3 Survivor co-op crate fix and hotfix 1.2.0.3, which fixes a wave-end crash while the Brachiosaurus foot is active on death or victory. The November 12 patch also adjusts modding internals for robustness, but each mod still needs its own compatibility check. A matching note is a reason to update and retry. Report version, steps and crash details if it persists. We have not validated individual packages or a universal crash fix.
