Choose an Azeroth Survivors mod for your client

For a meter or HUD, use an addon in the original client. For HD assets, inspect the Windows-only Overhaul requirements. Together and the community rebuild use separate client workflows. Choose the project and its supported version before downloading or moving progress.

Original-client addons: keep the browser and desktop paths separate

The browser accepts addon ZIPs through Options → AddOns → Install AddOns. Desktop users locate the folder through Open AddOns Folder and follow the author’s nesting requirements. An addon changes only what its own code and the client API support.

HD Overhaul: Windows files and your own asset source

finalpantasy’s README describes optional conversions for models, equipment, world assets and spell effects, alongside new content and a transactional installer. Its requirements name Windows 10/11, Python 3 and a Windows Azeroth Survivors folder. The documented game test target is v0.103.x. That target is older than later original-client references on this site.

HD packages require your own World of Warcraft install and the build named by the recipe. The repository says it distributes code and recipes, with no game executable or Blizzard assets. Its installer documents planning, verified backups, receipts and rollback. These are author-described features; this guide has not run the converters or verified restoration.

  1. Identify the Windows game version and make a separate backup of the game folder and exported progress.
  2. Read the chosen package’s recipe and identify the required asset build and reader dependency.
  3. Inspect the installer plan and backup requirements in the author documentation before applying a package.
  4. Retain the receipt and original files. Check the author’s rollback procedure before replacing further packages.

Together: choose its separate launcher deliberately

bymarvin’s Together repository documents a co-op installer/updater and launches through Start-Coop.cmd. It links a source repository for the DLL, network helper and updater. Its README describes signed releases, file checks, backups and rollback. This guide has not audited those mechanisms or joined a co-op session.

The original client’s Co-op menu and Together’s launcher are different setup paths. Follow the documentation for the client you actually selected. A separate folder or successful launch does not prove that saves, addons or multiplayer sessions transfer between them. Read the original-client co-op scope →

Community rebuilds: a repository is a separate version

OutThisLife’s repository describes a local from-source build using a Rust/Bevy client engine and points back to Aethus’s original game. Read its toolchain, data preparation and build instructions as a separate project. A guide for that code snapshot does not establish current original-client mechanics or addon compatibility.

Before changing a client or package

  1. Record the project author, release/tag, game version, platform and original game address.
  2. Export progress from the client and browser where it exists. Export the destination too before any import.
  3. Keep addon settings and a clean game folder separately where the project requires them.
  4. Change one package first, using the author’s installation method. Check menus and character progress before retaining the change.
  5. If a package fails, preserve the original and the release details. Follow its documented removal or rollback path.

Browser addon storage belongs to its browser and origin. A save import is not an addon transfer. The game validates imported save text and replacement can discard destination progress.

Can I install these mods in the browser?

The original browser addon installer accepts supported addon ZIPs. The Overhaul workflow described above targets Windows game files. Together supplies a separate native launcher. Their requirements cannot be substituted for each other.

Does a mod unlock everything? Each project needs its own documented feature and version evidence. For tools that edit progress, read the editor and import boundaries →. No current-client cheat table or all-unlocked save has been validated here.
