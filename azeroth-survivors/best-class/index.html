Which class should you choose?

Source changes detected: this editorial route needs review against the latest client. For a first melee character, consider Warrior; for a defensive holy route, consider Paladin; for ranged play, consider Hunter. Choose between them by the talents you have unlocked and how you prefer to move. These are editorial kit-based picks, not measured win-rate tiers.[1]

A tier list needs a progression state

A fresh hero, a character with a starting-spell milestone and a fully developed capstone character are three different comparisons. Permanent gear changes survival and damage again. If a guide recommends Hunter for pets, ask whether it means an early wolf or the wolf-and-raptor route. If it recommends Warrior for effortless Whirlwinds, check whether Bladestorm is already allocated.

How these recommendations are made

We compare the original client’s stated attack style, conditional talent engine and opening-spell changes. We do not combine old reconstruction health values with the current original talent tree. We have not measured clear rates or run a controlled damage test, so there is no universal S-to-D performance table. [1][2]
