Spend marks on equipped gear, not just a look

Permanent class gear lives in the Armory. Inspect Collection and Drop Tables, equip the piece, then check its star cap and marks cost. Cosmetic appearances and in-run jewelry are separate systems.[1]

Find the missing piece before repeating a zone

  1. Choose the class whose collection you want to improve. Gear and looks are kept per class.
  2. Open Collection and select the missing piece to inspect its bonuses and dropping bosses. Drop Tables organizes the same search by zone.
  3. Target a boss that can supply a piece still missing from this class. Each item has its own drop roll; the text says duplicates add nothing.
  4. Equip from the piece menu. Right-click equips/unequips; Shift+Right-click chooses a look. A displayed appearance does not by itself add stats.

The captured fresh Shaman collection is empty; it documents where to inspect items, not a successful loot or upgrade test.[1]

Upgrade checklist: permission, currency, benefit

CheckWhy it comes before spending
Correct class and itemMarks are class-specific. A cost copied from another item is not your next-star price.
Stars unlockedRead the Heroic/zone requirement on this piece. Having enough marks does not bypass the cap.
Next-star previewCompare the actual bonus you gain, rather than only the item colour.
Set thresholdFour armor pieces of one set at 1+ stars enable its four-piece bonus; all eight at 3+ enable its eight-piece bonus.
Empowered thresholdAll eight at five stars strengthen that eight-piece bonus by half again. Weapons and off-hands are not extra armor set pieces.

Our editorial order is to check whether the next affordable star completes a useful set threshold before spreading marks among unrelated pieces. That is a decision rule, not proof one set is best for every build.[1]

When an upgrade seems to do nothing

Check whether you only selected its appearance, whether the piece is actually worn and whether enough pieces meet the required star level. If the cap is locked, return to the named class/zone Heroic requirement. If fully upgraded, spend elsewhere. Do not mistake Codex discovery for permanent gear ownership. Exact costs and every class drop table are intentionally left to the current piece panel. Separate Codex jewelry from equipment →[1]
