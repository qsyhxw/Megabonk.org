Vampire Survivors co-op: can you play together?

Online co-op supports up to four players, but stores and ecosystems matter. Microsoft Store/Game Pass PC can pair with Xbox Series X|S; PS4 can pair with PS5. Steam-to-console and Xbox-to-PlayStation are outside the supported crossplay ecosystems. Check both copies below before buying or troubleshooting. [1]

By Megabonk.org · checked 5 November 2026 · Vampire Survivors is by poncle.

Start a compatible online session

  1. Launch the current commercial game on each player's own device. First check the two stores above; a code cannot fix incompatible ecosystems.
  2. Agree on the stage and DLC. The base game is enough for online play; for shared DLC content the FAQ requires every participant to own that pack.
  3. Choose Online from the main menu. One player hosts; the others join using the displayed room code. Xbox also has platform invites. There is no random public matchmaking.
  4. Choose from your own unlocked characters. The host's save controls which stages and items are available.
  5. When the run finishes, each player chooses whether to apply the group's progress to their own save. Check that choice before leaving.

These steps summarize the developer's documentation. We did not run a multiplayer session, check a subscription account or test DLC sharing ourselves. [1]

Same room or Remote Play?

Local co-op uses a shared screen; native online lets players roam independently. The current online FAQ says you cannot combine couch and native online players in one session. Every native-online player needs a separate device and game copy. [1]

For local PC play, the developer documents one input device per player. If one player uses the keyboard and another a controller, disable Assign Controller to Player 1 in the options. The image above is the developer's local co-op setting, not an Online lobby. [2]

On mobile, the local FAQ describes landscape orientation with Bluetooth controllers for additional players. That does not mean phone-to-PC native online is supported. Steam Remote Play Together is another route: it streams a local session, so treat it as shared-screen play with its own input and streaming limitations. It is not proof of native crossplay. [2][4]

The older local FAQ still contains launch-era wording that online co-op is unavailable. Use it for local inputs; use the separate current online FAQ for native-online availability and ecosystem rules. [1][2]

When a room code does not work

  1. Compare the exact storefronts, not just the operating systems. “We both play on Windows” does not establish compatibility.
  2. Check that both players selected the native Online mode rather than a shared-screen streaming session.
  3. Ask the host whether the run has already started. The FAQ says disconnected clients cannot rejoin a run in progress.
  4. Check the host connection: the FAQ says losing the host ends the session. A client disconnect is treated differently and the remaining players can continue.
  5. If the documented compatible setup still fails, record both stores, versions and the exact error before contacting poncle · support email ↗ (external website, opens in a new tab). Do not change or delete saves merely to fix a room code.

These checks separate incompatible setups from issues that need support; they do not promise a fix for every network error. Current rules and disconnect behavior: [1]
