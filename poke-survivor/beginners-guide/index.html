Your first Poke Survivor run

Open the original browser game, choose your Guest or account route, then pick a partner. Keep moving: the selected move attacks automatically. Learning four moves does not make all four fire together.[1]

By Megabonk.org editors · Checked October 26, 2026 · Source-based; no comparative gameplay test

中文说明：PokeSurvivor 中文入门攻略

Start on the original website

Use pokesurvivor.com — original English entry ↗ (external website, opens in a new tab). The author identifies this as the original website; a similarly named guide or hosted edition can have separate accounts and rules.[2]

  1. If you already have progress, return to the same address, browser profile and account first.
  2. For a new visit, choose Guest for a short look or sign in/create an account on the game site. Do not treat Guest as a cloud account.
  3. Follow the personality questions, then accept the suggested starter or choose another. The source lists 29 starting partners.
  4. Before a longer attempt, inspect Controls and the save/account status. This guide does not manage the account.
[3]

The author’s downloadable HTML edition is solo with browser saves. If you want friends, cloud saves or leaderboards, the author directs players to the online game.[4]

These are creator-documented defaults; saved control settings take priority. On touch screens, begin in landscape. Test a slot change in clear space before doing it in a crowded wave.[1]

A buff slot is not a damaging attack. If the field looks quiet after a switch, inspect the selected move before assuming the game froze. Bonds can join moves into one active slot; they are a separate progression system.

Read the offered card by what it changes

Level-up choices can teach a move, improve a learned move, change a run stat or evolve an eligible move. A run-stat card is not a permanent upgrade for every later attempt.[5]

Immediate problemRead this offer firstWhy
Low current HPSitrus Berry / VigorBerry heals 45% of maximum HP; Vigor adds 20 maximum HP and fills that added health in the checked source.

These are ways to read the choice, not a tested universal card order. In the checked source, once you already have two buff moves, further new buffs stop being offered. A full move/group layout is another reason not to expect every desired offer.

Move evolution is not a species unlock

For an eligible move, reach its maximum level, take its required run-stat card, then select the golden evolution card when offered. Read that move’s current requirement rather than assuming all attacks use the same stat.[6][5]

For example, the checked move definitions pair Ember’s evolution with Power and Quick Attack’s with Sprint. This does not mean the Pokémon species itself has permanently evolved or that its evolved species is now owned. Your collection, run moves and permanent partner upgrades are different records.

Use the Bond and active-group explanation before expecting linked attacks to fire together. This page is not a new full evolution database.

Before spending coins on permanent upgrades

Permanent improvements belong to the selected partner; a level-up card belongs to the current run. Confirm the partner name and the exact effect before spending. A later collected species is not automatically proof that an earlier partner’s upgrade spending moved with it.

Two separate feature requests ask for TM forgetting, and another asks for partner-upgrade resets. Requests are not evidence of an available refund. We have not verified an undo/refund route, so do not spend with the expectation of reversing it later.[7][8]

Finish by checking your save state

Before closing or changing devices, inspect the original game’s Save result. Local progress, a pending cloud upload and confirmed cloud success are different states. The checked source does not upload Guest progress as an online account.[9]

Keep the device with newer progress available if another device looks older. Follow the save-state checklist rather than clearing browser storage. That checklist does not promise to restore already lost data.

Rules below refer to JPTER78’s source snapshot 680c3e12c670, reviewed October 26, 2026. Other hosted editions and native ports can differ. We have not completed a comparative run or verified a universal fix.
