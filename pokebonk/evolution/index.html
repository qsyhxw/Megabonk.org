PokeBonk evolution, explained

Evolution follows your level inside the run, using thresholds calculated by the game and any League-specific overrides. Bulbasaur’s checked route is level 24 then 41; Charmander and Squirtle use 24 then 44. Eevee opens a choice at level 36 in this build.[1][2]

Checked October 26, 2026 · Beta v0.8.55 · Source-based guide

Read your next evolution before spending upgrades

  1. Inspect your selected partner’s League profile, rather than a profile for a different starting form.
  2. During a run, inspect the next-evolution indicator and its displayed level. A question mark can indicate a branch choice rather than missing data.
  3. Reach the threshold through run experience. The client checks evolution readiness before offering the next level-up choice.
  4. If you have already evolved later than expected, read the next indicator again: the planner enforces a minimum gap of three levels after the current evolution.

Animation timing, pending choices and whether the form’s sprite is available are separate from the numerical threshold. This guide does not promise that every animation begins at the exact instant the XP bar changes.[1]

Eevee is a choice, not a random-roll instruction

The current League entry defines Vaporeon, Jolteon and Flareon as Eevee’s branches and sets level 36. The run planner flags that branch and calls a selection menu when evolution is ready. Choose the displayed form there; do not follow an older guide that tells you to reset for a random branch.[1][2]

This is a client-verified interaction, not a completed Eevee run by this website. If the live menu changes, follow its actual options and check the version before assuming the old interaction still applies.

How the thresholds are derived

For a normal first stage that still has another evolution ahead, the client takes the next species’ raw level, adds 8, then clamps the result between 16 and 30. For a final evolution, it rounds 22 + 0.6 × the raw level, clamped between 36 and 50. A missing raw level uses a stage-dependent fallback.

League overrides take priority. Caterpie and Weedle use 8/36; Magikarp uses 40; Eevee has its own branch rule at 36. After an evolution, the next planned level is at least the current level plus 3. This is why merely reformatting the Pokédex’s raw evolution fields can give the wrong answer.

Our downloadable numeric reference contains these examples and their inputs. It is a small derived snapshot, not a copy of the game client: view the checked example data.

Evolution and a permanent League unlock are different

A run begins from the partner selected for it and evolves as that run progresses. Adding a partner to your League uses its own challenge and capture rules. Evolving the Pokémon you already control is not the same action as unlocking another starter or permanently starting every later run in the evolved form.

Why did my Pokémon not evolve at the main-series level?

Use this game’s transformed run threshold and League override. The raw Pokédex field alone is insufficient.

Do I need an evolution stone or a trade?

Do not infer that requirement from the raw species trigger. The checked run planner uses the level route and its overrides.

Does a delayed first evolution shift the next one?

It can: the next plan cannot be earlier than three levels after the current evolution.
