Choose your starting point

Revenant Survivors is Mongma Studio’s single-player dark-fantasy horde-survival roguelite. It entered Steam Early Access on November 9, 2026. The full game and free Demo have separate Steam listings. Use the listing for your intended edition.

Revenant Survivors full game on Steam ↗ (opens in a new tab) · Free Revenant Survivors Demo on Steam ↗ (opens in a new tab)

  • Trying the game. Start with the Demo listing and check its current requirements before installing.
  • Returning from the Demo. Open the full game first on the PC with your Demo save, inspect the imported progress, close the game and finish Steam Cloud syncing. Follow the save-transfer steps before continuing on another PC.
  • Preparing another run. Review the equipment you kept, Forge options and permanent upgrades. The progression guide explains how equipment, upgrades and appearance relate.

Decide what your next run should achieve

Boss powers and evolving attacks shape combat, while retained equipment, Skill Trees and Soul Engraving support growth between attempts. Choose a concrete goal before selecting the next stage.

  • Advance to later worlds. Hard Mode clears are required for World 5 and beyond. Check the selected world’s displayed unlock condition, then use the Hard Mode rewards and unlock guide.
  • Improve equipment. Hard Mode has increased item drop rates. Whether it produces more useful gear for your time depends on your ability to finish the run. Review the equipment preparation checklist first.
  • Change character appearance. The launch Supporter Pack contains cosmetic skins. Review the gear and skin distinction before choosing an upgrade or purchase.

Find help for the symptom you see

  • Basic Attack or Strike behaves unexpectedly. Check which attack the automation setting controls in the controller and auto-attack guide. It also separates historical playtest input reports from the current Steam support listing.
  • The screen stops after a run. Match the transition and game edition to the reported loading and crash fixes.
  • The full game opens without expected Demo progress. Check the original PC, first-launch sequence and Cloud status using the missing-progress checks.
