About the game

Azeroth Survivors is a free horde-survival game by Aethus, set in a Warcraft-inspired world and played at wow.aethus.pl in a WebGPU browser or from a Windows download. You pick one of nine classes and a race, move through the crowd while your spells fire automatically, choose upgrade cards during the run and spend talent points and gear between runs. It is a separate fan project, not Blizzard’s World of Warcraft or Megabonk: games with similar names.

Azeroth Survivors FAQ

Short answers; each links to the full guide.

What is the best class in Azeroth Survivors?

Warrior and Warlock are S tier in the current class rankings, followed by Mage, Hunter, Paladin in A tier. For a first clear, Paladin and Warrior are the most forgiving picks.

Tier list: all 9 classes →
What is the best Warrior build?

Take the Fury route: Rampage, then Flurry, then Blood Craze, then Bladestorm. Start with Cleave and add the Protection branch (Shield Slam support, Shockwave, Titan) once it is unlocked.

Warrior build →
How do talents work in Azeroth Survivors?

Runs earn class talent experience that you spend in Armory → Talents. The current menu caps you at 51 points, a new row opens for every 5 points spent in a tree, and respecs are free.

Talents: points & respecs →
Can you play Azeroth Survivors in a browser for free?

Yes. The original by Aethus runs free at wow.aethus.pl in a WebGPU-capable browser, and the same page links a Windows download.

Play Azeroth Survivors →
Does Azeroth Survivors have co-op?

Yes. Pick your hero, then press Co-op beside Enter to host a room or join with a code; the current client supports a party of up to five.

Co-op: host & join →
How do I move my save to another browser or PC?

Open Options → Saves and export a .sav file, then import it on the new browser or device. Import replaces the progress there instead of merging, so export both sides first if you want to keep both.

Save backup & transfer →
Why won't Azeroth Survivors load?

It needs WebGPU and a usable graphics adapter. Update the browser, turn on hardware acceleration and let the first game-data download finish; the fixes page matches each error message.
