Which earlier advice can you reuse?

An older page can still explain a condition correctly, but a matching talent name is not proof every value is unchanged. Our earlier eight-class route research is labelled v0.127.0; the present Warlock addition is checked separately against v0.130.0. New system pages state their current menu/text scope. No complete cross-class DPS reranking or all-rank compatibility test was performed. If a current tooltip differs, follow the client and report the build, talent name and discrepancy.[1]
