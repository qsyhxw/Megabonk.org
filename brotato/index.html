If installed content is missing

  1. Confirm the DLC is owned by the account running the base game.
  2. In Steam Library → Brotato → Properties → DLC, check installation.
  3. Update and restart the game.
  4. Open Item Sets from Character Selection and inspect Primal Dread.
  5. If the issue persists, record the game version, branch and active mods before asking support.

The developer’s 1.2 announcement explains that Item Sets can disable expansions and free updates. A missing shop item can be an enabled-content issue. Use the mod checklist if the updated game crashes.

Choose expansion content by the run you want

Primal Dread adds the Jungle, Evolution and new characters, weapons and items. Abyssal Terrors is a separate expansion. If your goal is learning the base loop, begin with a simpler enabled-content set. Choose Primal Dread when you want to manage the trade-off between stronger weapon or item scaling and changed enemy hazards. Use our Evolution guide to understand that decision.

Playing the optional beta? The 10 November beta-1 patch changes Evolution rewards and shop controls. Check the branch guide and Evolution choices before copying a launch build.

New Dawn appears separately in Item Sets. It is not another name for Primal Dread. See the update and branch guide when a video appears to show different rules.
