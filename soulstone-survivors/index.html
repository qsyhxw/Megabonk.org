About the game

Soulstone Survivors is a 3D horde-survival action roguelite by Game Smithing Limited. Steam App 2066020 left Early Access on 17 June 2025 (Early Access began 7 November 2022) and lists Windows, macOS and Linux. The official site also links PS5 and Xbox Series versions; the links we checked do not list Nintendo Switch.

Mod instructions here apply to their documented Windows versions. Official pages: Steam ↗ · Official site ↗.

How we check

Each guide names its sources, the date we read them and what a source does not show. Community builds are reports, not our tests, and we do not claim a tested all-character tier list.

Common questions

Is Soulstone Survivors single-player?

Steam lists the base game as single-player. On Windows, fan mods add separate online and same-PC co-op routes; they are not official multiplayer support. Co-op choices →

Do the co-op mods work with the current game?

Each author documents one game version: the online README targets 1.5.3.2 and the local README was tested on 1.5d2. Match the version and loader before installing, and keep a backup. Mod compatibility →

What is the Bumble crystal order?

Activate the five winter circles in red, blue, yellow, green, purple order. Kill a boss that drops the matching colour of major Soulstone inside its circle; standing in the circle is not enough. Crystal order →

Is there a Soulstone Survivors tier list?

Not here. The sources we checked do not establish a tested ranking for every character and mode, so we publish a build checklist and a Barbarian comparison instead. Build checklist →

What should I do first as a new player?

Use early runs for permanent upgrades and one damage plan you can describe. After a clear, decide whether you need a safe return to spend resources or a harder continuation. Beginner guide →

Is Soulstone Survivors on console or Switch?

Steam lists Windows, macOS and Linux. The official site links PS5 and Xbox Series versions; the links we checked do not list Nintendo Switch, which is not a promise that a port will never happen. Start here →

Is there a Russian build guide?

Yes. The Russian page explains skill types, chains and replacements for builds; English skill names are kept so you can compare the source text. Билды на русском →
