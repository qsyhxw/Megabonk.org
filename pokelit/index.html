A practical first-session route

  1. Finish sign-in on the game site. Use the same account on each device if you want the project's documented cloud-save path. If you use a name and password, the account notice offers Gmail linking for recovery.
  2. Choose a partner, then begin a run. Movement and positioning are your active tasks. Moves fire automatically, so repeatedly tapping enemies is not the basic attack loop.
  3. Collect experience and read the level-up cards. Choose a new move, a move upgrade or a partner boost. Your run has up to four moves. For a first session, track those slots before replacing something you meant to upgrade.
  4. Move out of filling ground markers. Those circles and lines telegraph attacks. Make room to dodge before collecting a pickup in that area.
  5. Review permanent upgrades between runs. Coins can strengthen a favorite partner. Use an early session to learn movement before treating an unverified tier list as a reason to replace that partner.

This route combines the entry screen with the original gameplay guide ↗ (opens in a new tab). It is setup guidance rather than a tested optimal build.

Separate similar names before using a guide

PokéLit / pokelit game / pokelit survivor refer here to the game at pokelit.0d4y.cc. Its own credits say it is based on PokéSurvivor by JPTER78. Shared ancestry does not establish shared accounts, identical versions or interchangeable progression instructions.

PokéSurvivor has its own section on this site. PokeBonk is another separate game. Open the matching game first, then use that game's guides. Pokémon Survivors and Pokelike searches can lead to other projects, so check the address and title before applying advice.

Pokelit AA and Acebeam Pokelit are flashlight names. Pokelit.com describes a Pokémon card collection service. Neither is the browser survival game covered here. “Pokelite” alone is ambiguous and does not establish a download destination.
