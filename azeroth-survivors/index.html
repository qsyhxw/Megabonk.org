Which game did you mean?

Looking for the Warcraft-themed game with automatic spells? This guide covers Aethus’s Azeroth Survivors at Aethus · original browser game. Descriptions such as “WoW roguelike”, “WoW Vampire Survivors” or “WoW Megabonk” can point to this style of game; they do not make it Blizzard’s World of Warcraft, Vampire Survivors or Megabonk itself. Choose the actual game and host before using a build or moving a save.

Is Azeroth Survivors made with AI?

As of 5 November 2026, we have not found a verifiable statement from Aethus identifying which AI tools, if any, were used to develop the original game. Community descriptions such as “vibe coded” remain claims. A separate author’s reconstruction or another WoW project cannot establish the original creator’s workflow. The visible game credit identifies Aethus; it does not document development tools. See the captured creator credit.

The community rebuild README identifies a separate local build and points to the original. This is an entity check, not evidence for an AI-generated percentage or a statement that the original used no AI.

Who is Aethus? What does “zuzia miau miau” refer to?

The original character-menu screenshot shown on this page credits “Made by Aethus (zuzia miau miau)” at the bottom left. This is the visible creator credit in the English v0.130.0 menu captured on 30 October 2026 and re-read on 2 November. It identifies the game credit; it does not establish a legal name, another account’s identity or a separate download site.

For the game itself, use Aethus · wow.aethus.pl. Check the full spelling, including the .pl ending, when returning from a search result. Our Play guide opens the original game in its own tab.
