Start your first Azeroth Survivors run

Open wow.aethus.pl in a WebGPU-capable browser. Pick a hero, move while spells attack automatically, and choose upgrades when the card offer appears. Keep the cards for this run separate from the talents and equipment you develop between runs.[1][2]

From the original page to a run

  1. Open Aethus’s original game ↗ (external website, opens in a new tab). Keep this guide in a separate tab. The original does not run inside this website.
  2. Allow the initial game-data download to finish. A loading bar is different from a WebGPU warning or a server quota message.
  3. Choose your hero and inspect the class, selected talents and starting spell. A developed character may start with a different spell from a new one.
  4. Start the run with Enter. Move to leave room around the hero, collect experience and read the offered upgrade’s effect before selecting it.
  5. When the run ends, inspect permanent progress and prepare the next attempt. Export a save before changing browser, device or host.

These are the original picker and menu prompts, reviewed 29 October 2026. Use Options → Controls / Key Bindings for the current full binding list instead of importing keys from a different reconstruction. [1]

Three decisions that should stay separate

DecisionWhen to make itWhat to compare
Run cardsDuring the level-up offerThe spell you currently use, the trigger it needs and the problem it solves now.
Permanent talentsBetween runsPrerequisites, opening-spell changes and the engine you can actually unlock.
Permanent equipmentBefore comparing another runKeep the starting investment similar; do not credit the entire difference to one card.

Match a launch problem to the next step

What you seeWhat to checkWhat this does not prove
Game-data downloadLet the download progress; note whether the counter changes.A black loading surface alone is not proof of a broken save.
No WebGPU warningUse a current Chrome, Edge or Safari and check GPU availability. The launcher also suggests a Linux Chrome WebGPU flag.A browser version alone does not guarantee a usable GPU adapter.
Too many people are playingUse the original page’s Windows download or original community link; a quota is not fixed by changing class.The hidden warning text in HTML is not evidence the server is currently full.
Different progressReturn to the previous browser/profile/origin, then export before migrating.A new host does not automatically inherit old storage.
