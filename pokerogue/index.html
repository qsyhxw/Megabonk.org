Start with the original game

  1. Choose Play on pokerogue.net above. The original game opens in a new tab.
  2. Use your PokeRogue account or choose the original game’s registration option. This is an account-based game, not a guest-play demo.
  3. Follow the original game’s menus to begin or continue your run. Keep this guide tab open to check encounter choices.

On a small screen, the original’s touch controls and a larger landscape window can help. For browser shortcuts and community offline-app differences, use the mobile guide below. Do not assume a community app shares the web game’s account or saves.

About this game entry

PokéRogue is a fan-made, turn-based Pokémon roguelite by the Pagefault Games project. This independent page links to the original pokerogue.net ↗ (opens in a new tab) game; Megabonk.org does not operate the game, accounts or saves. It is a different game from PokeBonk and other similarly named Pokémon projects.

Checked 6 November 2026 against the original client and project repository ↗ (opens in a new tab). The original game opens in a separate tab and may change independently of these guides. Pokémon names and artwork belong to their respective owners.
