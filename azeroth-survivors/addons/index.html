Install an addon in the right client

In the browser, use Options → AddOns → Install AddOns and select the author’s ZIP. On desktop, use the AddOns folder opened by the game and match the folder name to its .toc file. Browser installation and desktop extraction are different paths.[1][2]

ASBuilder: plan offers, not a talent allocation

ASBuilder is Cadoky’s community build planner and in-run tracker. Its author documents spell target ranks, jewelry priorities and Early / Mid / End / Endless stages, with a tracker for the next planned choice. Open it with /asb or its book button. [6]

  1. Use GitHub · ASBuilder author project ↗ (external website, opens in a new tab) to find the current release and requirements. For desktop, the author places the ASBuilder folder in benilla-config/AddOns and restarts the game; the browser ZIP path below is a separate installation route.
  2. Set the spells and jewelry you intend to use, including alternatives, before relying on the tracker. A priority is your plan, not a guarantee that the game will offer that card.
  3. Export a plan as an ASB2 code to share it; keep the code separate from your game-save backup. Importing a plan does not recover heroes or equipment.
  4. Check the plan after a patch, especially if starting spells or talent interactions changed. The author says addons cannot read talent data: its talent screenshot link is a reference, not validation of a legal 51-point allocation.

We read the documentation on 2 November 2026; we have not installed the addon, tested browser support or validated its examples against the latest original patch. Check talent gates in the game → · Export actual progress separately →[6]

Which UI project did you mean?

Start with the stock interface if you only need the built-in meter. A replacement HUD changes more of the screen; compare its documented controls before adding another package. Several projects use similar Survivor UI names, so match the repository owner as well as the addon name. Author documents checked 3 November 2026; these packages were not installed here.

Browser: keep the ZIP intact

  1. Download the chosen addon ZIP from its author.
  2. Open the original game’s Options → AddOns → Install AddOns.
  3. Choose the ZIP and inspect the installed entry; enable the addon in the list.
  4. Start the next run so the game can load it. Install an updated ZIP through the same menu when the author releases one.

The browser installer stores files in IndexedDB for that browser and origin. They do not automatically follow the save file to a second device; clearing site storage can remove them. [2]

Desktop: check the directory level

  1. Open Options → AddOns → Open AddOns Folder in the downloaded game.
  2. Extract the author’s addon into that folder. For AZS Spell Meter the author documents AddOns/AZSSpellMeter/AZSSpellMeter.toc.
  3. If the extracted directory is AZSSpellMeter-main or has another wrapper folder, rename or move the actual addon folder so its name matches the .toc.
  4. Relog as the addon author instructs, then check the addon entry again.
