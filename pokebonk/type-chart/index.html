Check PokeBonk’s own type multipliers

PokeBonk transforms the familiar type chart: favorable matchups use 1.35×, resisted ones 0.8× and classic immunities 0.5×. Dual-type results are multiplied and clamped to 0.4–1.8× before the separate matching-type bonus.[1]
