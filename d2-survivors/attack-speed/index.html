Compare speed upgrades using Survivors rules

In the checked original reference, each point of item Increased Attack Speed adds half a point of Faster Cast Rate. Attacks and skills share the resulting speed system, and there are no D2R-style breakpoints. Compare the displayed total and the affected skill instead of copying a Diablo II gear threshold.

This example assumes the item line has its full applicable weight. For dual-wielded weapons, the reference weights each weapon’s IAS at half before that conversion; a +20 IAS line on one of those weapons therefore contributes +5 FCR, not +10. It is not a named-item recommendation or a promise that 20 more points means 20% more final DPS. The original character screen’s item preview is the useful next check.

Raw speed is not final recharge reduction

The reference applies diminishing returns and class-dependent caps. It explicitly says there are no breakpoints, so a D2R breakpoint table answers a different game’s question. Compare two items with your current class and skill present, keeping damage and defenses in the decision too.

A skill also needs a valid target before it casts. Item skill modifiers and innate hastes can affect recharge; an idle or rested skill is not evidence that a speed item failed.

Use the same host and a controlled comparison

  1. Note the game host and build, class, skill and current equipment.
  2. Read the displayed total before and after the one item change.
  3. Keep the skill, target situation and other equipment fixed if you compare actual cast behavior.
  4. If your display disagrees, keep the screenshot and exact item lines; do not transplant a newer formula into an old hosted edition.

Players asked whether familiar Diablo II speed rules carried over. This guide separates that question from damage-per-second rankings. We have not timed a benchmark or established the current best item.
