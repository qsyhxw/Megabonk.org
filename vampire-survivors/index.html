02 / TRY THE ORIGINAL

Open the original demo

Yes: poncle still hosts a free browser demo on itch.io. It is the old v0.2.4 Demo, not the current commercial game or its online co-op edition. Open it on the author's site; this guide explains the first steps and what will not carry over.

poncle on itch.io · open the original demo ↗ (external website, opens in a new tab)

Use poncle.itch.io/vampire-survivors, then select Run game. You are leaving Megabonk.org to play on the author's page. We do not embed this page: its response policy allows framing only within its own itch.io context. No game is loaded by reading this guide.

Startup checked in desktop Chrome on 5 November 2026: Run game → title → Start → Antonio → Confirm → Start → active battlefield. The client displayed v0.2.4 - Demo. Keyboard movement and automatic whip attacks were observed in a short opening check; no complete run or physical-phone test is claimed.

Start your first run

  1. After Run game, click inside the game if it is still showing the title artwork. The main menu has a blue Start button.
  2. Choose Start. On a fresh profile Antonio is available; the other visible starting portraits may still be locked.
  3. Choose Antonio, select Confirm, then Start. In our fresh demo check this entered the grassy battlefield directly.
  4. Use the arrow keys to move away from the approaching enemies. Attacks fire automatically, so movement and collecting experience are the first jobs.

The author recommends concentrating levels in two or three offensive weapons instead of spreading upgrades thinly. Experience gems and dropped items do not immediately disappear, so avoid diving into a dangerous crowd just to collect them. These are the author's tips, not a promise that one build always wins.

If keyboard input does nothing, click inside the game once before pressing an arrow key. The author lists mouse, keyboard, controller and touch support, but this check covered desktop keyboard input only.

Full game: genre, dates and Switch 2

Vampire Survivors is a time-survival action roguelite: move through enemy crowds while weapons attack automatically, then choose upgrades as you gain levels. This is the gameplay loop sampled by the old browser demo; it is not a traditional manually aimed shooter. Steam lists 17 December 2021 as Early Access and 20 October 2022 as the full release. Those are Steam dates, not a claim that every console launched that day.

Can you use a Switch 2? Nintendo currently marks the Nintendo Switch version as supported on Switch 2, with behavior consistent with Switch. That compatibility listing alone does not establish a separate native Switch 2 edition, an upgrade price, mouse controls or a measured frame-rate improvement. Check the actual version label before purchasing an upgrade. Nintendo · Switch edition and Switch 2 compatibility ↗ (external website, opens in a new tab) (checked 9 November 2026).

If your next step is playing with a friend, use the device and storefront check rather than treating hardware compatibility as crossplay. For modern weapon recipes and unlocks, Vampire Survivors Wiki ↗ (external website, opens in a new tab) covers the full game; modern recipe lists do not describe everything available in this older one-stage demo.

Keep demo progress separate

The author's itch.io FAQ says the web demo save cannot be transferred to Steam. Do not start a long demo run assuming it will become your full-game save. A login to itch.io is not evidence that the game has cloud-save migration.

Use the same original host and browser profile if you return to the demo. Clearing site data or switching browser contexts can affect browser-stored progress; recovery and migration were not tested here. The current commercial game's account or cross-save features do not establish compatibility with this older demo.

Looking for multiplayer?

The modern full game supports online co-op, but its rules do not apply to this old browser demo. Use our platform and storefront check before buying a second copy or troubleshooting a room code. The developer's current FAQ is the authority for supported pairs.
