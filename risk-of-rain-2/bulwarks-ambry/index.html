Risk of Rain 2 Bulwark's Ambry: entry, keys and reward

Short answer: On stage 5 (Sky Meadow or Helminth Hatchery) find the Compound Generator, enter the artifact's nine-cell code and use the laptop to open the portal. Inside, use the four Artifact Keys on the Artifact Reliquary one after another, then pick up the artifact it leaves.

Compiled from published guides, not our own playthrough. Updated 24 November 2026. Читать на русском

Where the entrance is

Bulwark's Ambry is a hidden realm opened from the Compound Generator, and the generator exists only on two fifth-stage maps.

Where you areWhat to do
Sky Meadow (stage 5)Drop through a hole in the floor into a room under the map with the Compound Generator and a laptop.
Helminth Hatchery (stage 5, Seekers of the Storm)The Compound Generator is at the very top of the map.
Any other stageNo entrance. A normal Teleporter does not lead to the Ambry.

Entering the code

You need the code of the artifact you want to unlock; the codes are listed in sabo.gg's artifact guide ↗. The code is a 3×3 grid of cells. Each press cycles a cell through square, circle, triangle, then diamond, and the code is read top to bottom, row by row. When the grid matches, use the laptop. A correct code opens a purple portal; enter it.

Rebirth is the exception: it has no code. According to sabo.gg you get it by offering an item to the Shrine of Rebirth at the end of Prime Meridian, a Seekers of the Storm map.

The trial: four Artifact Keys

  1. Pick up the first Artifact Key in front of the Artifact Reliquary.
  2. Interact with the Reliquary while holding the key. Enemies start to spawn.
  3. Kill enemies until one drops the next key, pick it up right away and return to the Reliquary.
  4. Repeat until the fourth key is used. Each key removes a quarter of the Reliquary's health.

Only keys damage the Reliquary, so regular attacks are wasted. Using a key also removes every other key held by all players or lying on the ground, so do not stockpile them.

The artifact you are unlocking is already active during the trial. sabo.gg notes that this is easy with Command and harder with Frailty or Death.

If the trial stalls

What you seeWhat to check
No portal after using the laptopRecheck all nine cells. Each press cycles square, circle, triangle, diamond, and the code is read top to bottom, row by row.
Enemies appear but the Reliquary takes no damageNormal attacks do nothing to it. Pick up the Artifact Key that dropped and interact with the Reliquary while holding it.
A teammate lost their keyUsing any key removes every key from all players and the ground, by design. Use the current key first, then wait for the next drop.
The artifact is not in your list next runPick it up from the destroyed Reliquary first, then enable it in the artifact menu before starting the run.

Reward and exit

Pick up the artifact from the destroyed Reliquary before leaving. You keep it permanently and can enable it in the menu before any run; in co-op the group can enable any artifact that any player owns, per sabo.gg. The portal after the Reliquary leads to a stage 1 map, and leaving the Ambry this way counts as a loop. Your run continues with everything you carry.

How this was checked

Both sources agree on the Sky Meadow and Helminth Hatchery entrances and on four keys. Neither states a game patch number, so check the current patch notes if a step behaves differently. We did not test this in game.
