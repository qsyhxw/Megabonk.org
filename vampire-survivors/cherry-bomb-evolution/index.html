Cherry Bomb evolution and the Cavallo level-80 route

Obtain Chaos Rosalia, then reach character level 80 while playing as Yatta Cavallo. His transformation evolves Cherry Bomb into Yatta Daikarin automatically. The normal route uses the relic and Cavallo’s level, so opening more treasure chests will not replace those conditions.

The official patch notes describe the transformation at character level 80. They do not specify a max-level Cherry Bomb plus passive-and-chest recipe. Our common evolution chart covers that other pattern.

Unlock and select Yatta Cavallo

Defeat a cumulative total of 3,000 Lion Heads, then purchase Cavallo in character selection. Lion Heads appear in Inlaid Library. Cavallo begins with Cherry Bomb, which makes him the direct character choice for this route.

The historical gameplay image below identifies Cavallo’s small panda-like form. It shows the character before the large morph and does not document a level-80 trigger or a current-version completion test.

Find Chaos Rosalia in Astral Stair

  1. Unlock Astral Stair by reaching level 80 in Inverse Inlaid Library. Normal Library and Inverse Library are different settings for this objective.
  2. Enter Astral Stair and explore its connected rooms through the doors. Obtain the stage map if you need a clearer view of the room layout.
  3. Locate the Chaos Rosalia relic using its map position and green directional arrow, then walk over the relic to collect it.
  4. Return to character selection and start a Cavallo run with the relic effect enabled.

Old-layout reference. The June 2023 walkthrough describes the upper side-door route in the starting corridor, passing through successive rooms to the right. The very end door loops to the opposite end of the corridor. Source descriptions disagree about compass directions, so use the relic icon and arrow when your layout differs. This guide does not claim a freshly tested door-by-door route for every current edition.

Reach level 80 and identify the result

Gain experience as Cavallo until his run level reaches 80. With Chaos Rosalia active, Cavallo morphs and Cherry Bomb becomes Yatta Daikarin. The evolved weapon continues throwing bombs and adds constellation-like explosions around the character.

Collecting the relic persists between runs. The character’s run levels and weapon upgrades belong to the current run, so the permanent relic unlock should not be read as a promise that every future character starts with the evolved weapon.
