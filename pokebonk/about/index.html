About this guide

Megabonk.org · Updated November 16, 2026

This PokeBonk section is an unofficial player guide published by the editors of Megabonk.org, an independent site for survivors-style games. It is not run by the game’s developer and is not game support.

Who owns the game?

PokeBonk is a free fan game led by Charcher and played at pokebonk.com. This guide is not affiliated with Charcher, Nintendo, The Pokémon Company, Creatures or GAME FREAK. Pokémon names and game images belong to their respective rights holders. Our seed-compass mark identifies this guide, not the game.

What this section covers

Copyable builds, the build planner and move fusions; the tier list and starter choice; reference data in the Pokédex, evolution levels, type chart and Lab costs; run help such as the beginner guide, catching partners and Mewtwo; and platform questions on mobile, co-op and loading problems.

Where the answers come from

  • The public game client: partner kits, moves, items, Lab costs and type multipliers are read from the game data that pokebonk.com loads in the browser, without running a modified game.
  • The game’s own update notes and menus: version changes, events and modes are checked against the in-game update notes and menu screens.
  • The original project’s public pages: the legal and credits notice and its linked community channels for ownership, accounts and support.

A value in the game data is not a measured win rate or a device test. Pages keep dates and versions next to the answers, and we do not label something as tested when it was not.

How pages stay current

A monitor reads the public game client every six hours. The latest version it detected is v0.10.29 (November 24, 2026). Reference tables update once new data passes validation; changes that cannot be validated automatically keep the last reviewed data until an editor checks them. See patch changes for what the current version changes.

Corrections and image requests

Send the page URL, the detail that is wrong, the game version you see and a screenshot or public source through the contact page. Rights holders can use the same address for image or content requests.
