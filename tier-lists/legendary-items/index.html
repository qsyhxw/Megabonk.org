Quick Answer

Giant Fork is one of the strongest broad damage picks once Crit is online. Overpowered Lamp leads on-hit builds, while Anvil, Pot, Wizard's Hat, Joe's Dagger and Sucky Magnet become exceptional when the run matches their scaling condition. A lower-rarity item can still be the correct choice if it completes your build.

How This Ranking Works

Tier measures general run value, not a mandatory pick order. The rating combines immediate impact, late-run scaling, trigger reliability, build coverage and how late the item can appear before its effect loses value.

S — Build Defining

High ceiling with reliable value in the right route.

A — Strong

Excellent effects with narrower build or timing requirements.

B — Conditional

Useful when the trigger solves a specific problem.

U — Unranked

No dependable power value for route planning.

Choose by Build, Not Color

Crit / Overcrit

Prioritize Giant Fork after Crit is established. Overpowered Lamp matters only if the same run also carries supported proc items.

Long Run / Leaderboard

Joe's Dagger, Anvil, Pot, Wizard's Hat, Sucky Magnet and Soul Harvester improve with kills, levels or run length.

Poison

Snek supplies Poison stacks and burst potential. Dragonfire belongs to Fire routes instead of being forced into Poison.

Sustain

Chonkplate is the broad Lifesteal anchor. Holy Book fits healing-heavy setups; Za Warudo is emergency insurance, not ongoing sustain.

Proc / Multi-hit

Overpowered Lamp, Lightning Orb, Ice Cube, Spicy Meatball, Big Bonk and Power Gloves reward frequent hits.

Short Stage Clear

Prefer immediate effects. Late Anvil, Pot, Wizard's Hat or Joe's Dagger may not have enough time to repay the pickup.

Legendary Drops and Luck

Luck can improve rarity outcomes, but it does not guarantee a Legendary roll or a particular item. The exact chest formula is not published in the official patch notes, so this page does not use a fixed drop percentage or claim that zero Luck blocks Legendary items.

Unlocking an item and seeing it during a run are separate steps. Check the item detail page for its prerequisite, then make sure it is available in your active item pool.

Legendary Items FAQ

What is the best Legendary item in Megabonk?

Giant Fork is a leading general damage pick once Crit is established. Overpowered Lamp is better for supported proc builds, while Anvil, Pot, Wizard's Hat, Joe's Dagger and Sucky Magnet can outperform it in longer specialized runs.

Are Legendary items always better than Epic items?

No. Rarity affects availability, not whether an effect solves the current build's problem. A matching Epic can be more useful than an unrelated Legendary.

Does Luck guarantee Legendary items?

No. Luck can improve rarity outcomes, but it does not guarantee a Legendary or a specific item.

Why is Golden Ring unranked?

Its description says it does not seem to do anything, so it is not treated as dependable build power.
