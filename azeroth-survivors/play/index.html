Start in the game window

  1. Press Play Azeroth Survivors above and let the hosted game finish preparing its world data.
  2. Read the character and zone choices in the game before starting. Our beginner guide and class builds cover the original host and name their checked version; this hosted client may differ.
  3. Click inside the game for keyboard focus. Check the game’s own input settings before relying on a key or controller mapping.

Expand gives the game more browser space. Hide and Return keep the same frame loaded; they do not pause the game. Pause inside the game first. On small screens, try landscape. Browser-size checks do not establish physical-phone compatibility.

Keep this edition and your original save separate

This window uses the same third-party game address linked by azerothsurvivors.online, checked 31 October 2026.[1] We do not host the executable, operate its servers or claim an official partnership. The menu displayed v0.90.0 (ac6aefc3), with nine zones, on this check. The original-game guides checked v0.130.0 separately. Version parity, addon support, account transfer and save compatibility are unverified.

Our desktop browser startup check on 31 October reached Elwynn Forest’s Jasperlode Mine with a Warrior. Movement started the run; the timer reached 00:06 and the Level 2 card choice appeared. This is a short startup check, not a completed run, multiplayer test, save-transfer test or physical-phone benchmark. Initial resource and world-data preparation took several minutes.

The original Aethus game at wow.aethus.pl blocks third-party frames, so its direct link opens a separate tab.[2] Keep existing progress at the address and browser profile that created it. Before experimenting with an import, keep an unchanged export from each client; importing is not a way to merge progress. See the original-game backup guide.

Loading this game connects your browser to its host and services. We cannot read its cross-origin storage or recover its saves. See the game-window privacy notice.

If loading takes a long time

The first world-data preparation can continue after the outer window reports that it loaded. Watch the progress inside the game. Hiding and restoring the window preserves the current frame; repeatedly reloading starts a new page session.

If it stalls, try the same hosted game in its own tab ↗ (external website, opens in a new tab). If that provider is unavailable, use Aethus’s original game ↗ (external website, opens in a new tab); it is a separate host, so this session does not automatically follow. Our browser and mobile checks distinguish graphics support from input and storage.
