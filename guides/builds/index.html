Megabonk Build FAQ

Quick answers about choosing a Build and interpreting synchronized leaderboard evidence.

What is the best Megabonk Build?

There is no single best Build for every character or mode. Start with the character-specific Best Build, then compare version-matched leaderboard evidence.

Are leaderboard Builds always current?

Not necessarily. This Hub shows the leaderboard data version and sync time. If it differs from the latest game version or manual review baseline, treat it as ranked evidence and check the latest patch changes.

How do I find a Build for my character?

Use the character search or selector, then open that character's Best Build page for Weapons, Tomes, Items and progression. Use the Character Guide for unlocks, passive mechanics and the starting weapon.

Why is the leaderboard version different?

The synchronized leaderboard can retain runs from an earlier game version or lag the newest patch. The Hub labels leaderboard data and editorial review versions separately so they are not presented as identical.
