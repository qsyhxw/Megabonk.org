Set the right Archive for your build

Open Lab → Items to review your archived items, then select the build plan you intend to use. An archived item is excluded from Poké Ball and shop offers. In v0.9.21 the item contribution became one slot per unlocked item. Check the active plan before changing the pool.

Megabonk.org · Updated November 11, 2026 · v0.9.23

Calculate slots with the current rule

The v0.9.23 definition gives 5 × purchased Archive level + unlocked eligible item count, with the item contribution enabled only after buying at least level one. The upgrade has six levels. Level zero supplies zero slots. Level one with ten unlocked eligible items supplies 15 slots, and level three with 21 supplies 36. These are arithmetic examples.

The old rule added one slot per two items. Its historical 59-slot maximum is unsuitable for the current roster. Read the live counter before buying a level. Our Lab calculator retains an older reviewed inventory.

Check a copied build before a run

  1. Choose the Pokémon and named plan in Builds. Inspect missing and locked choices.
  2. Check whether that plan has its own Item Archive. Version 0.9.21 introduced this option. Version 0.9.23 adds an explicit warning for it.
  3. Compare every wanted item with that Archive. Return a wanted item to the pool before beginning a new run.
  4. Review type-item filters in the Build Plan, introduced in v0.9.19. They can travel with a shared build without changing the Lab Archive.
  5. Check the attack Archive separately. Season 3 allows per-Pokémon attack exclusions while preserving at least twelve attacks. The latest notes fix archived attacks returning.

Keep templates and saved runs consistent

Season 3 expands item Archive templates to twelve across four pages. Use a recognizable name for each purpose. Compare a recovery-oriented plan and a damage plan with the same Pokémon, difficulty and upgrades before deciding which pool helps you.

The v0.8.81 rule preserves the Archive that a saved run already had. Changing the pool before Continue affects a new run. Version 0.8.85 announces account-backed build plans and Archive templates. Check the same original account when switching devices.

When the item you want never appears

Inspect unlock state, active plan, its own Archive, Lab template, type filters and whether you resumed an older run, in that order. A correct pool still offers random choices. It cannot promise that a particular item appears on the next roll.
