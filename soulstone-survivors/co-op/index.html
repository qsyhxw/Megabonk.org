Choose online or local co-op

The base game lists single-player. On Windows, fan mods offer separate online and same-PC routes. Choose by where your friends play, then match the author’s game and mod versions; this is not official multiplayer support.

The online author advertises up to eight players but reports real Steam testing with two; larger groups were tested only on one PC. Treat the capacity as an experimental limit, not eight-player stability evidence.

Online: install, invite, then start

Use the GitHub · author’s Releases ↗ alongside these checks. The page is an external download destination, not our mirror.

  1. Close the game. Back up your saves and note any loader already installed. Match the release instructions to your game version.
  2. In Steam, open Manage → Browse local files. Extract the author’s package so winhttp.dll and BepInEx sit beside Soulstone Survivors.exe.
  3. Start through Steam and allow initial loader preparation. A Co-op tab indicates that the plugin loaded.
  4. Host sends a Steam invite; guest accepts. If that fails, use the author’s invite-code route. Host chooses the map and starts Fight.

The README distinguishes Steam relay invitations from direct IP. Start with Steam invitations rather than changing router settings for an unrelated connection method.

Same PC: controllers and package choice

The local author’s README 1.3.0 distinguishes a full “completo” package from a mod-only package for an existing BepInEx installation. Do not stack two full packages. Close the game, extract the selected package into its folder and connect one controller per extra player; one keyboard/mouse counts as one player. First launch prepares libraries and can appear frozen for 1–3 minutes.

Open the author’s GitHub · local-mod instructions ↗ for the controls belonging to the downloaded version. This guide does not turn a local mod into online play.

Before trusting a long run

Online rejoining does not preserve a run by default; Crusade is unsupported, and leaving as host ends the group’s run. The author also notes missing partner aura/channel visuals. An absent effect on the guest’s screen is not enough to diagnose lost damage.

For rollback, remove only the files installed by that package, following its uninstall list. If a loader was already shared with another plugin, restore your pre-install folder instead of deleting that shared loader blindly. We have not installed either mod or verified saves, achievements or long-session stability.
