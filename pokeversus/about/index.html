About the PokéVersus guide

Megabonk.org editors · Facts reviewed 22 November 2026 · Checked against original client v2.37

Who runs this section

This is an unofficial fan guide published by the editors of Megabonk.org. We are not Fl3xix (Chacoon Studio), who makes PokéVersus, and we do not run pokeversus.com. Pokémon names and artwork belong to Nintendo, Creatures Inc., GAME FREAK and The Pokémon Company, and this guide is unaffiliated with any of them.

What it covers

The guide page loads the original game in a window on click, then walks through the login window, trainer name and starter choice, the mode list, what a guest and an account save, and which similarly named games are different projects.

Where the answers come from

  • The original game: the login window, starter selection, hub and mode list were captured from the browser client at pokeversus.com ↗, entered as a guest.
  • The patch feed: the version number and recent changes come from the game’s own news.js ↗ feed, read on 5 November 2026.
  • Our own checks: a guest start through to the mode list at desktop and phone-width viewport sizes. No full or ranked match, account sign-up, clan war, cross-device save or physical phone was part of the check, and the frame itself accepts input only inside its own origin.

How the page stays current

The page shows the client version and the date it was checked. The game updates often, so the version line and the mode list are the first things to recheck when the feed shows a new release.

Corrections

Send the page URL, the host you used (the original site or our game window), the version shown at the bottom of the client and what you saw through the contact page. A confirmed error is corrected on the page and the check date updated.
