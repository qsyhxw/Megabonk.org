Start with the original game

  1. Choose Play on pokerogue.net above. The original game opens in a new tab.
  2. Use your PokeRogue account or choose the original game’s registration option. This is an account-based game, not a guest-play demo.
  3. Follow the original game’s menus to begin or continue your run. Keep this guide tab open to check encounter choices.

On a small screen, the original’s touch controls and a larger landscape window can help. For browser shortcuts and community offline-app differences, use the mobile guide. Do not assume a community app shares the web game’s account or saves.

Choose your first run

Classic: Pick one attacker with a useful starting move, then spend the remaining points on a teammate who can switch into its weaknesses. For example, pair a Fire attacker with a Grass starter to cover Water and Ground opponents. A purple frame on starter select means Pokérus and bonus experience. When two options fill the same job, use that as a tiebreaker.

Daily Run: Everyone starts with the same seeded team. Plan for 50 waves and five biomes. The Map lets you choose between offered routes. The seed changes at midnight UTC. A run saved before rollover can still be finished. See the Daily Run rules ↗.

Map in Classic: At a biome boundary the Map offers connected destinations. For example, leaving Town with the Map can offer Plains, Metropolis or Lake. An optional connection can be absent on a given roll. Check the biome connections ↗ before choosing.

Menu and eggs: On a default keyboard press M or Esc to open the menu, or X or Backspace to cancel a selection. Spend vouchers in Egg Gacha. A hatch unlocks a future starter. The Golden Egg held item instead gives its holder 100% extra EXP. See the egg guide ↗ and held-item definitions ↗.

About this game entry

PokéRogue is a fan-made, turn-based Pokémon roguelite by the Pagefault Games project. This independent page links to the original pokerogue.net game; Megabonk.org does not operate the game, accounts or saves. It is a different game from PokeBonk and other similarly named Pokémon projects.

Checked 6 November 2026 against the original client and the project repository ↗. The original game opens in a separate tab and may change independently of these guides. Pokémon names and artwork belong to their respective owners.

Common questions

Do I need an account to play PokeRogue?

Yes. The original game opens an account screen first, so this is an account-based game rather than a guest demo. Sign-in, registration and saves are managed by pokerogue.net, not by this site.

Full answer →
Can I play PokeRogue on my phone?

Start at pokerogue.net in your mobile browser. A home-screen shortcut opens the same web game, while the community offline app is a separate wrapper. We did not test a physical phone, so check the mobile guide before installing anything.

Full answer →
Should I accept the Dark Deal?

Refuse if your run cannot survive losing an essential team member. Accepting removes a randomly selected Pokémon and opens a catchable boss fight, in return for five Rogue Balls.

Full answer →
Trash to Treasure: dig or investigate?

Digging avoids the fight but makes shop items and rerolls cost 2.5 times as much for the rest of the run. Investigating risks a Garbodor boss battle and lets you choose a reward afterward.

Full answer →
Will my saves move between the browser and the offline app?

The community wiki says data can transfer from online to offline, but not back. Treat an offline run as a separate commitment and keep a backup through the supported export process.

Full answer →
Is this the same game as PokeBonk?

No. PokeRogue is a turn-based Pokémon roguelite by the Pagefault Games project; PokeBonk and other similarly named Pokémon projects are different games with their own pages.

Full answer →
Can I catch Eternatus on my first Classic clear?

Only if you have already unlocked every other starter. Ordinary Classic checks your starter collection before ball strength or the remaining boss shields.
